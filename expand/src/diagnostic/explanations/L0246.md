A `rust` form may list clauses after its type, each a target and a template. A
call picks a clause by the type that the `where`'s type parameter takes at that
call. A plain `fn` type has no type parameter, and so does a `where` that binds
only lifetimes, such as `(where ('a) ...)`. A `where` that binds two type
parameters has too many. All three are this error.

A clause that is not a list of a target and a template, such as a bare type,
reports `L0210` before the parameters are counted. A `deftype` with clauses and
a parameter count other than one reports `L0223`.

## Erroneous example

```lisp
(def larger
  (rust "std::cmp::max({0}, {1})"
    (fn (i64 i64) i64)
    (i64 "i64::max({0}, {1})")))

(defn main ()
  (println (larger 3 5)))
```

## Fixes

Write the type with a `where` whose parameter the clause can match:

```lisp
(def larger
  (rust "std::cmp::max({0}, {1})"
    (where ((a ord)) (fn (a a) a))
    (i64 "i64::max({0}, {1})")))

(defn main ()
  (println (larger 3 5)))
```

When the type is concrete, the template alone is enough:

```lisp
(def larger
  (rust "i64::max({0}, {1})"
    (fn (i64 i64) i64)))

(defn main ()
  (println (larger 3 5)))
```
