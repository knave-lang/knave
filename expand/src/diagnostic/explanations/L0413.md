A `where` type introduces type parameters and the traits they require. A `type`
declaration, the type of a `rust` form and an entry of a Rust trait's
implementor list accept it as the outermost form of their type. This error
reports a `where` at any other position, such as a parameter or the result of a
function type, a type argument as in `(vec (where (a) a))`, the referent of
`ref`, a `deftrait` method's parameter, a `struct` field, a `defenum` payload,
or the body of another `where`. A `the` annotation reports it too, even when the
`where` is the outermost form of the annotation's type.

A `where` that is the whole type of a `deftrait` method reports `L0210` instead.

## Erroneous example

```lisp
(type size (fn ((ref (where (a) (vec a)))) usize))

(defn size (items) (len items))

(defn main () (println (size (ref (vec 1 2)))))
```

## Fixes

Move the `where` out, so that it holds the function type:

```lisp
(type size (where (a) (fn ((ref (vec a))) usize)))

(defn size (items) (len items))

(defn main () (println (size (ref (vec 1 2)))))
```

Or drop the type parameter, and name the item type:

```lisp
(type size (fn ((ref (vec i64))) usize))

(defn size (items) (len items))

(defn main () (println (size (ref (vec 1 2)))))
```
