A struct field or an enum payload declared with a function type, such as
`(fn (i64) i64)`, holds a Rust function pointer. A function pointer holds a
named function or a closure that captures nothing, because it has no room for
captured values. This closure captures a value and reaches such a field.

The closure can reach the field through `new`, a constructor, `assoc` or a
variant. It can sit inside a value that the field's type holds, such as an
`option` through `some`, or a `vec`. It can arrive directly, through a `local`,
through a branch of an `if` or a `match`, through the last form of a `do`, or
as an argument to a function or a local closure that stores its parameter in
the field. A capturing closure that no such field holds is fine.

## Erroneous example

```knave
(defstruct counter
  :next (fn (i64) i64))

(defn main ()
  (local step 2)
  (local by-step
    (->counter :next (fn (n) (+ n step))))
  (println ((:next by-step) 1)))
```

## Fixes

Store a closure that captures nothing:

```knave
(defstruct counter
  :next (fn (i64) i64))

(defn main ()
  (local by-step
    (->counter :next (fn (n) (+ n 2))))
  (println ((:next by-step) 1)))
```

Or store the captured value in a field of its own, and pass it to the function
as an argument:

```knave
(defstruct counter
  :next (fn (i64 i64) i64)
  :step i64)

(defn advance (counted n)
  ((:next counted) n (:step counted)))

(defn main ()
  (local step 2)
  (local by-step
    (->counter :next (fn (n by) (+ n by))
               :step step))
  (println (advance by-step 1)))
```
