`recur` starts the nearest enclosing `fn`, `defn` or `loop` again. This
error reports a `recur` in the value of a module-level `def` that no
function encloses, wherever it sits in that value, such as a branch of an
`if`.

## Erroneous example

```knave
(def start (recur 10))

(defn main () (println start))
```

## Fixes

Define a function, and call it from the `def`:

```knave
(defn count-down (n)
  (if (= n 0) 0 (recur (- n 1))))

(def start (count-down 10))

(defn main () (println start))
```
