Each value gets one concrete type in the emitted Rust. This error reports a
value whose type, or a part of whose type, nothing in the program fixes by the
end of checking. Examples are the element type of a `(vec)` that nothing adds to
or reads as a known type, the payload type of `none`, and the target type of
`parse`. An unused `let`, a value passed to a parameter that ignores it, and an
unused parameter of a closure report it too. `main` reports it when it returns a
`result` with an open part, such as the error type of `(ok 5)`. A function whose
bound names a type that no argument or result holds reports it at a call,
because no call fixes that type.

A field read or a struct update on a value whose type is still unknown at that
point finds the struct by the field's name. A read reports `L0408` when no
struct declares that field. When several do, the read gives its owner a field
bound, and it reports this error unless the function is a plain reader: only
structs with no open type argument reach it, they read the field as one type
that is not a function, holds no type variable and is exactly the type its body
uses and each call passes, the body fixes all of the read or none of it, no
bound ties the read to another type variable, no other read joined with it gives
another type, the function changes no place reached from the owner and uses a
non-Copy owner only to read its fields, a read that stores a borrow, or borrows
a Copy owner taken by value, cannot leave it through its result, a parameter or
a closure, no other field gives the same trait name, and no trait method of the
program takes the getter's name. An update reports it when no struct, or more
than one, declares every field that it names. A `type` signature that names the
struct fixes the type. A read whose value is an integer or float literal that
nothing has fixed reports `L0410`.

## Erroneous example

```knave
(defn main ()
  (let (names (vec))
    (println (len names))))
```

## Fixes

State the element type in a `the` form:

```knave
(defn main ()
  (let (names (the (vec string) (vec)))
    (println (len names))))
```

Or give the vector an element, which fixes its type:

```knave
(defn main ()
  (let (names (vec "ana"))
    (println (len names))))
```
