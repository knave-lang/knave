A label in a struct pattern, or in the pattern of a variant with named fields,
names a field, and the label is the last part of the pattern, as in `(point
:x)`, or the next part is another label, as in `(point :x :y b)`.

A pattern checks its labels in the order written, so a label that names no field
or a label used twice reports its own error when it comes first or is itself the
label with no pattern: `(point :z)` reports `L0460` and `(point :x a :x)`
reports `L0461`, as does any label on a variant with a positional payload, such
as `(circle :radius)`. A pattern that also holds a positional part, such as
`(point a :y)`, reports `L0462` first.

## Erroneous example

```knave
(defstruct point :x i64 :y i64)

(defn main ()
  (match (->point :x 1 :y 2)
    ((point :x :y b) (println b))))
```

## Fixes

Match `:x` with the name `a`:

```knave
(defstruct point :x i64 :y i64)

(defn main ()
  (match (->point :x 1 :y 2)
    ((point :x a :y b) (println a " " b))))
```

Or match only `:y`, because a labeled pattern skips the fields it does not
name:

```knave
(defstruct point :x i64 :y i64)

(defn main ()
  (match (->point :x 1 :y 2)
    ((point :y b) (println b))))
```
