A symbol made of `:` and a field name, such as `:year`, is a field keyword.
Every place that binds a name reports this code when the name is a field
keyword, such as a `let` binding, a `fn` parameter, a `def`, a binder in a
`match` pattern, a type variable that a `where`, a type's head or an `impl`'s
implementor binds, or the name that a definer such as `defstruct` defines.

Two places take a keyword without binding it. A `defn` parameter list that
starts with a keyword declares keyword parameters, and the body names each one
without its `:`. Inside a variant or struct pattern, a keyword labels the field
that the next pattern matches, and a variant or struct with no such field
reports `L0460`.

## Erroneous example

```lisp
(defstruct car :make string :year u16)

(defn main ()
  (let (car (->car :make (str "Nissan") :year 2024)
        :year (:year car))
    (println :year)))
```

## Fixes

Bind the value to a plain name:

```lisp
(defstruct car :make string :year u16)

(defn main ()
  (let (car (->car :make (str "Nissan") :year 2024)
        year (:year car))
    (println year)))
```
