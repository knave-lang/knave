A trait describes what many types can do, and is not a type of its own. This
error reports a trait's name written where a type belongs, such as the type of
a parameter, a field of a `struct` form, an element of `(vec ...)`, the target
of `ref`, a `the` form, or the target of a `rust-type` clause. It covers a
trait that the program defines and a trait that `rust-trait` binds, such as
`display` or `clone`.

Inside `(box ...)`, a trait that the program defines makes a trait object, and
`L0448` reports when that trait cannot make one. A trait in the bounds of a
`where`, as in `(where ((a shape)) (fn (a) i64))`, is a bound, not a type.

## Erroneous example

```lisp
(deftrait shape
  (area (fn ((ref self)) f64)))

(defstruct circle :radius f64)

(impl shape circle (area (c) (:radius c)))

(defn report ((s shape)) (println (area s)))

(defn main () (report (->circle :radius 2.0)))
```

## Fixes

Leave the parameter's type out, and the call of `area` gives it a bound on
`shape`:

```lisp
(deftrait shape
  (area (fn ((ref self)) f64)))

(defstruct circle :radius f64)

(impl shape circle (area (c) (:radius c)))

(defn report (s) (println (area s)))

(defn main () (report (->circle :radius 2.0)))
```

Or take any implementor through a `(box shape)` parameter:

```lisp
(deftrait shape
  (area (fn ((ref self)) f64)))

(defstruct circle :radius f64)

(impl shape circle (area (c) (:radius c)))

(defn report ((s (box shape))) (println (area s)))

(defn main () (report (box (->circle :radius 2.0))))
```
