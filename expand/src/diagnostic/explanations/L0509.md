A closure's body decides how often it may run. A closure that moves a capture,
or a field of one, runs at most once, so its kind is `FnOnce`. A closure that
changes a capture may run many times, one call at a time, so its kind is
`FnMut`. Any other closure is `Fn`. A closure also takes the kind of what it
does to a captured closure, and one that consumes a captured iterator pipeline
is `FnOnce`, because a pipeline runs once.

A function parameter accepts a kind. A written `fn-once` or `fn-mut` type on a
`defn` parameter is exact. Otherwise knave infers the weakest kind the body's
uses allow. A call that is the parameter's only use, and cannot repeat, accepts
`FnOnce`. A call that a `loop`, a `recur` or a second use can repeat needs
`FnMut`, and uses in different branches of an `if` or a `match` are not counted
together. An unused parameter needs only `Fn`. The prelude's iterator adapters,
such as `map`, take `fn-mut`. A parameter of a `local` closure accepts at most
`FnMut`, even with a written type, unless the closure is also used as a value.

This call passes a closure, or a function parameter, whose kind is stronger than
its parameter accepts.

## Erroneous example

```lisp
(defn twice (action)
  (action)
  (action))

(defn main ()
  (local name (str "Leaf"))
  (twice (fn ()
           (local moved name)
           (println moved))))
```

`twice` calls `action` two times, but the closure gives `name` away on its first
run.

## Fixes

Clone the capture, so each run gives away its own copy:

```lisp
(defn twice (action)
  (action)
  (action))

(defn main ()
  (local name (str "Leaf"))
  (twice (fn ()
           (local copied (clone name))
           (println copied))))
```

Or call the parameter once, so it accepts `FnOnce`:

```lisp
(defn once (action)
  (action))

(defn main ()
  (local name (str "Leaf"))
  (once (fn ()
          (local moved name)
          (println moved))))
```
