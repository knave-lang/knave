`knave task` runs a task by its name, so each name may belong to one task of
the project. This error reports two `deftask` forms under `tasks/` that give
their tasks the same name, whatever their parameters and bodies. The two forms
may sit in one file or in two files anywhere under `tasks/`. The compiler
reports the error at one of the two names and marks the other.

The error comes from the step that collects the names of every task, so
`knave task`, `knave task <name>` for any name, and `knave check` with no file
report it. `knave check` of one file under `tasks/` does not, and neither do
`knave build` and `knave run`, which do not read `tasks/`.

## Erroneous example

```lisp
;; knave task tidy
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/clean.knv
(deftask tidy () (println "tidying the desk"))

(deftask tidy () (println "tidying the shelf"))
```

## Fixes

Give the second task a name of its own:

```lisp
;; knave task tidy-shelf
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/clean.knv
(deftask tidy () (println "tidying the desk"))

(deftask tidy-shelf () (println "tidying the shelf"))
```

Or merge the two into one task, with a flag that picks the work:

```lisp
;; knave task tidy --shelf
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/clean.knv
(deftask tidy (:shelf false)
  (if shelf
    (println "tidying the shelf")
    (println "tidying the desk")))
```
