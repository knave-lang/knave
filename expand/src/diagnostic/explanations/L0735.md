This error reports an entry in the `lints` section of `project.knv` whose first item is a string, a number or a list. Each entry starts with the lint's name, written bare: the name that `knave doc <code>` shows for an `L08xx` code, with dashes in place of its spaces.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter (lints ("unused-binding" allow)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Write the name without quotes:

```knave
;; project.knv
(defproject greeter (lints (unused-binding allow)))
;; src/main.knv
(defn main () (println "hello"))
```
