A function whose name ends in `!` may change its parameters with `set!`, and the
caller sees each change in the place it passed. The argument must be a place
that the caller can read afterwards, such as a local or a parameter. A computed
value, a `def`, and an element that a call borrows are not such places, so the
change would reach nothing the caller reads.

## Erroneous example

```knave
(defn bump! (n) (set! n (+ n 1)))

(defn main ()
  (bump! (+ 1 2)))
```

## Fixes

Store the value in a local, pass the local, and read it afterwards:

```knave
(defn bump! (n) (set! n (+ n 1)))

(defn main ()
  (local count (+ 1 2))
  (bump! count)
  (println count))
```

Or return the new value instead of changing the argument:

```knave
(defn bumped (n) (+ n 1))

(defn main ()
  (println (bumped (+ 1 2))))
```
