A call in macro code runs the value at the head of the list, so that value
must be a function, such as a `fn`, a helper defined with `defn`, or a
built-in of the `code` module. This error reports a head that evaluates to a
value of any other kind, such as a string, a number, a symbol, a boolean or a
list. A macro's parameter holds a form, not a function, so writing it at the
head of a call, as in `(text "!")`, reports this error.

To build a call for the program to run, return it as a list, as with `list`
or `template`.

## Erroneous example

```knave
(defmacro shout (text)
  (text "!"))

(defn main ()
  (println (shout "hello")))
```

## Fixes

Build the call as a list:

```knave
(use code list)

(defmacro shout (text)
  (list (quote println) text "!"))

(defn main ()
  (shout "hello"))
```
