A `deftrait` or `rust-trait` with a Rust path binds a trait name to that
Rust trait, and lists the types the program may use it for. This warning
reports a trait whose Rust path is written exactly as a trait already in
scope writes its own, such as a second trait for `std::fmt::Display` beside
the prelude's `display`, or a new `display` that binds `display`'s path
again. Each trait accepts only the types it lists, so a function bounded by
`printable` below refuses an `f64`, which `display` accepts.

## Erroneous example

```knave
(deftrait printable
  (rust "std::fmt::Display")
  i64 string)

(type framed
  (where ((a printable))
    (fn ((ref a)) string)))

(defn framed (value) (str "[" value "]"))

(defn main () (println (framed 5)))
```

## Fixes

With the prelude's trait:

```knave
(type framed
  (where ((a display))
    (fn ((ref a)) string)))

(defn framed (value) (str "[" value "]"))

(defn main () (println (framed 5)))
```

For a different Rust trait:

```knave
(deftrait hex-number
  (rust "std::fmt::LowerHex")
  i64 u8)

(def hex
  (rust "format!(\"{{:x}}\", {0})"
    (where ((a hex-number))
      (fn ((ref a)) string))))

(defn main () (println (hex 255)))
```
