A name refers to a binding that is visible where the name is written: a
parameter, a `local`, a definition of the same module, or a name that a `use`
imports. The name here matches none of them. The usual causes are a misspelled
name, a name that another module defines but this module does not import, and a
local used outside the body that binds it.

## Erroneous example

```knave
(defn distance (from to) (- to from))

(defn main () (println (distnce 1 4)))
```

## Fixes

Correct the spelling:

```knave
(defn distance (from to) (- to from))

(defn main () (println (distance 1 4)))
```

Or define the name, when no definition exists yet:

```knave
(defn distnce (from to) (- to from))

(defn main () (println (distnce 1 4)))
```

A name that another module defines needs a `use` of that module, as in
`(use geometry distance)`.
