A `defstruct` may end with a `(defaults ...)` clause that gives a value to
some of its fields, each written as the field's keyword and the value. This
error reports a key of that clause that names none of the struct's fields,
such as a misspelled field or a field the struct does not declare.

A default whose key is not a keyword reports `L0301`. The same mistake in the
`(defaults ...)` clause of a `defn` with keyword parameters reports `L0323`. A
call of the constructor, such as `->user`, that labels an argument with an
unknown field reports `L0408` instead.

## Erroneous example

```lisp
(defstruct user :name str :admin bool (defaults :admin? false))

(defn main () (println (:name (->user :name "ana"))))
```

## Fixes

Name the field as the struct declares it:

```lisp
(defstruct user :name str :admin bool (defaults :admin false))

(defn main () (println (:name (->user :name "ana"))))
```

Or declare the field under the name that the default uses:

```lisp
(defstruct user :name str :admin? bool (defaults :admin? false))

(defn main () (println (:name (->user :name "ana"))))
```
