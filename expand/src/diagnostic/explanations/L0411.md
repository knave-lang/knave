The type checker infers each value's type by solving equations between types.
This error reports an equation that asks an unknown type to equal a type built
from that same unknown, such as `t` and `(vec t)`, or `t` and a function type
that takes `t`. No finite type solves it.

Such an equation comes from code such as a parameter called with itself, as in
`(f f)`, `(push! items items)`, a comparison such as `(= x (vec x))`, or a
recursive call that passes its parameter wrapped in `some`. The equation forms
only while the type is unknown, so when a signature writes the type of `x`,
`(= x (vec x))` reports `L0401` instead.

## Erroneous example

```knave
(defn main ()
  (let (items (vec))
    (push! items items)
    (println (len items))))
```

## Fixes

Push an item rather than the vector itself:

```knave
(defn main ()
  (let (items (vec))
    (push! items 1)
    (println (len items))))
```

Or, to build a vector of vectors, push a new inner vector:

```knave
(defn main ()
  (let (rows (vec))
    (push! rows (vec 1 2))
    (println (len rows))))
```
