`quote` returns a form, a value that macro code works on while the compiler
expands the program. This error reports a `quote` form in the program's own
code: in `main`, or in a function or `def` that the program reaches from `main`,
at any depth, including inside a `fn`. A `template` of a form that is not a
list, such as `(template hello)`, is a `quote` too.

A function or `def` that holds a `quote` and that `main` does not reach, such as
one that only macros use or that nothing uses, reports nothing. A `quote` in a
method of an `impl` reports nothing. A `template` of a list builds the form with
functions of the `code` module, and reports `L0412` instead.

## Erroneous example

```knave
(defn main () (println (quote hello)))
```

## Fixes

Replace the quoted symbol with a string literal:

```knave
(defn main () (println "hello"))
```

Or let a macro return the `println` call as code:

```knave
(defmacro say-hello ()
  (quote (println "hello")))

(defn main () (say-hello))
```
