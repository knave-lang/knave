A struct, an enum or a Rust type declares a fixed count of type parameters, and
each written use of its name passes one type for each of them. This error
reports a written type whose name gets a different count of types, such as `(vec
i64 i64)`, a bare `vec` or `(option)`, or `(point i64)` for a struct declared
with no type parameters. It covers every place a type is written, such as a
signature, a `the` annotation, a `struct` field, an enum payload, the value of
an associated type, and an associated type used as a projection. Lifetime
parameters do not count, so a struct whose only parameter is a lifetime is
written bare.

A type parameter given types, as in `(a i64)`, and a lifetime passed as a type,
report `L0212` instead.

## Erroneous example

```knave
(type size
  (fn ((ref (vec i64 i64))) usize))

(defn size (items) (len items))

(defn main ()
  (println (size (ref (vec 1 2)))))
```

## Fixes

Give `vec` its one item type:

```knave
(type size (fn ((ref (vec i64))) usize))

(defn size (items) (len items))

(defn main ()
  (println (size (ref (vec 1 2)))))
```

Or, for items that hold two numbers each, make the item a `pair`:

```knave
(type size
  (fn ((ref (vec (pair i64 i64)))) usize))

(defn size (items) (len items))

(defn main ()
  (println (size (ref (vec (pair 1 2))))))
```
