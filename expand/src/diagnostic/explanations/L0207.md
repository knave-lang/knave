A module holds only definitions, such as `defn`, `def`, `defstruct`, `use` or
`export`, and a top-level `do` whose forms are all definitions. A module
evaluates nothing when it loads, so nothing runs any other form at the top
level: a call such as `(println "starting")`, a lone value or name, an `if`, a
`local`, or a macro call whose expansion is not a definition. Each form inside a
top-level `do` follows the same rule.

In `knave repl`, a `do` entered at the prompt that holds a definition reports
this error on its forms that are not definitions.

## Erroneous example

```knave
(println "starting")

(defn main ()
  (println "running"))
```

## Fixes

Run the call from `main`:

```knave
(defn main ()
  (println "starting")
  (println "running"))
```

Or bind the value to a name with `def` and use the name:

```knave
(def greeting "starting")

(defn main ()
  (println greeting)
  (println "running"))
```
