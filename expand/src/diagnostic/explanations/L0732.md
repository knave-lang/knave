This error reports an entry of the `lints` section of `project.knv` that gives no level: a lint's name alone, or an entry that is no list. An entry is a lint's name, then its level.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter (lints (unused-binding)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Give the lint a level:

```knave
;; project.knv
(defproject greeter (lints (unused-binding warn)))
;; src/main.knv
(defn main () (println "hello"))
```
