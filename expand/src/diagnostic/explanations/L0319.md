A `rust` form holds Rust source that the compiler writes into the emitted
program, and only that program runs it. Macro code runs inside the compiler
while it expands the program. This error reports a `rust` form written in macro
code, such as one in a macro body, in a branch that never runs, or in a function
that the body calls.

The compiler checks this when it defines the macro. A name whose definition is a
`rust` form, such as `sqrt`, and a macro that expands to one, such as `print`,
report `L0306` instead.

## Erroneous example

```lisp
(defmacro answer () (rust "40 + 2" i64))

(defn main () (println (answer)))
```

## Fixes

Compute the value with the built-ins of `code`, such as `number-add`:

```lisp
(use code number-add)

(defmacro answer () (number-add 40 2))

(defn main () (println (answer)))
```
