A `type` declaration of a function fixes its signature, so inference never
widens or narrows it. This warning reports a declaration that changes nothing:
removed, it leaves every function's signature and the emitted Rust exactly as
they are. A declared `(ref x)` parameter that inference would pass by value
counts too, and the help names each parameter that will then pass by value,
because its type is small enough to copy. A declaration in a module other
than the entry module must also change nothing when that module is checked
alone, as `knave doc --types --file` checks it: removed there, it leaves the
type of every function that the module defines as it is. In a project,
`knave lint` tries every program it lints, the test and task programs
included, and a declaration that any of them needs stays silent.

A declaration that inference needs stays silent: one that keeps a function
generic or narrows it, picks a number type that a literal would not, places a
trait bound, settles a recursion, types a function that nothing calls, or
gives a function of its module a type that the module alone would not infer. A
declaration that writes a lifetime always stays, and so does every
declaration inside a docstring example.

The lint is off unless the project file turns it on, as
`(defproject demo (lints (needless-type warn)))` does, because finding it
costs about one more check of the program for each `type` declaration that
it keeps. Only `knave lint` runs those checks, and only at `warn` or `deny`:
`knave check`, `knave build` and `knave run` never run them.

## Described example

The explanation tests check programs without running the lint rules, so they
run none here. In this program, inference gives `cell-count` the type its
declaration writes, so `knave lint` reports the declaration once the project
turns the lint on:

```text
(defstruct grid
  :width int
  :height int
  :cells (vec bool))

(type cell-count (fn ((ref grid)) int))

(defn cell-count (grid)
  (* (:width grid) (:height grid)))

(defn main ()
  (println (cell-count (->grid :width 3 :height 4 :cells (vec)))))
```

## Fixes

Remove the declaration:

```knave
(defstruct grid
  :width int
  :height int
  :cells (vec bool))

(defn cell-count (grid)
  (* (:width grid) (:height grid)))

(defn main ()
  (println (cell-count (->grid :width 3 :height 4 :cells (vec)))))
```

Or keep a declaration that changes the signature, such as a narrower result:

```knave
(defstruct grid
  :width int
  :height int
  :cells (vec bool))

(type cell-count (fn ((ref grid)) i32))

(defn cell-count (grid)
  (convert (* (:width grid) (:height grid))))

(defn main ()
  (println (cell-count (->grid :width 3 :height 4 :cells (vec)))))
```
