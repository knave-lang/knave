A project file holds one form, the `defproject` form, with every setting and
section inside it. This error reports a project file with a second form at its
top level, such as a section written after the closing parenthesis of
`defproject`. It reports the second form once, however many forms follow it.

Every command that reads the project reports it, run in the project's folder or
below it, or given a file there: `knave check`, `types`, `lint`, `expand`,
`emit`, `build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```lisp
;; project.knv
(defproject greeter)
(libraries)
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Close the `defproject` form after the section:

```lisp
;; project.knv
(defproject greeter
  (libraries))
;; src/main.knv
(defn main ()
  (println "hello"))
```
