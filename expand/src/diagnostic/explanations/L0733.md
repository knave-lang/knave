This error reports a number in the `lints` section of `project.knv`. A number would set a rule's threshold, such as how many lines a function may hold, and no lint rule has one.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter (lints (unused-binding 20)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Give the lint a level instead:

```knave
;; project.knv
(defproject greeter (lints (unused-binding warn)))
;; src/main.knv
(defn main () (println "hello"))
```
