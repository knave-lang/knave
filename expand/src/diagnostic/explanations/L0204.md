A `use` names a module by its path, and no module the program can load has this
path. The path may be misspelled, may name a folder instead of a file, or may
carry the file's `.knv` extension. In a task, a `use` also reports this error
when the file exists but the task cannot reach it, such as a module under
`tests/`.

Macro code reports the same error when `module-exports`, `module-definitions` or
`module-symbol` names a module that the program has not loaded, and so does the
`(module path)` term of a documentation lookup such as `doc-page`. The modules
`kernel`, `code` and `prelude/internal/code`, which the compiler provides, have
no file, so `module-symbol` and a documentation lookup cannot name them either.

## Erroneous example

```lisp
(use prelude/macro document)

(def limit 10)

(document limit "How many items a page shows.")

(defn main ()
  (println limit))
```

## Fixes

Correct the path:

```lisp
(use prelude/macros document)

(def limit 10)

(document limit "How many items a page shows.")

(defn main ()
  (println limit))
```

Or drop the `use` when the file needs nothing from the module:

```lisp
(def limit "How many items a page shows." 10)

(defn main ()
  (println limit))
```
