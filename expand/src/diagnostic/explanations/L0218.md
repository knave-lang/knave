A `rust` form's template is Rust text in which `{0}` stands for the first
argument, `{1}` for the second, and so on. This error means a single `{` in
the template opens no such placeholder: a `{` that never closes, as in
`{0 * 2`, a `{}` with nothing inside, as Rust's own `format!("{}", x)`
writes, or a borrowed `{&name}` with a name in place of a position. The check
covers the template that follows `rust` and each `(type "template")` clause
after the form's type.

## Erroneous example

```lisp
(def double (rust "{0 * 2" (fn (i64) i64)))

(defn main ()
  (println (double 21)))
```

## Fixes

Close the placeholder:

```lisp
(def double (rust "{0} * 2" (fn (i64) i64)))

(defn main ()
  (println (double 21)))
```

With a format string:

```lisp
(def bracketed (rust "format!(\"{{}}\", {0})" (fn (i64) string)))

(defn main ()
  (println (bracketed 5)))
```
