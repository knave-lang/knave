A Rust template declares a result that holds a reference, and its parameters
hold more than one reference between them, but no lifetime says which of them
the result borrows from. Knave tracks what a result borrows so that it can stop
a change to a value while the result still reads it, and it cannot tell that
from the declared type. Rust's own signatures refuse the same declaration
(rustc's `E0106`). A parameter such as `(ref (ref str))` counts twice, because
it holds two references.

## Erroneous example

```knave
(def later
  (rust "std::cmp::max({0}, {1})"
    (fn ((ref str) (ref str)) (ref str))))
```

## Fixes

Name the parameter the result borrows from with a lifetime, and write the same
lifetime on the result. Write it on every parameter the result can borrow from:

```knave
(def later
  (rust "std::cmp::max({0}, {1})"
    (where ('a)
      (fn ((ref 'a str) (ref 'a str)) (ref 'a str)))))
```

When the result borrows from only one of them, write the lifetime on that one
alone, and the others stay free to change while the result lives:

```knave
(def without-prefix
  (rust "{0}.trim_start_matches({1})"
    (where ('a)
      (fn ((ref 'a str) (ref str)) (ref 'a str)))))
```
