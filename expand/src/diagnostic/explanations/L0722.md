This error reports a library name whose entries, in the project file and in the
project files of the libraries it lists, lead to two different folders, such as
`hints` at `hints` in the project and at `other-hints` in a library's project
file. It reports the entry that the compiler reaches second, as it follows each
library's own libraries before the next entry. Two names for one folder do not
report it.

The commands that read the project report it as they follow its libraries, and
libraries' own libraries, and stop at the first such problem: `knave check`,
`types`, `lint`, `expand`, `emit`, `build`, `run`, `test`, `task`, `eval`,
`repl`, `doc --write`, `add` and `remove`. `knave fmt` reports it as a warning
and formats the files all the same.

## Erroneous example

```knave
;; project.knv
(defproject greeter
  (libraries (hints :path "hints") (tips :path "tips")))
;; src/main.knv
(use hints hint)
(use tips tip)

(defn main ()
  (println (hint) (tip)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
;; tips/project.knv
(defproject tips
  (libraries (hints :path "../other-hints")))
;; tips/src/lib.knv
(export tip)

(defn tip () "world")
;; other-hints/project.knv
(defproject hints)
;; other-hints/src/lib.knv
(export hint)

(defn hint () "hi")
```

## Fixes

In `tips/project.knv`, write the `:path` of the folder that the project lists:

```knave
;; project.knv
(defproject greeter
  (libraries (hints :path "hints") (tips :path "tips")))
;; src/main.knv
(use hints hint)
(use tips tip)

(defn main ()
  (println (hint) (tip)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
;; tips/project.knv
(defproject tips
  (libraries (hints :path "../hints")))
;; tips/src/lib.knv
(export tip)

(defn tip () "world")
```
