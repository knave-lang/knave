The binding list of `let`, `loop`, `let-try` and `let-match` pairs each name,
or each pattern in `let-match`, with the value that follows it. This error
reports a binding list with an odd number of items, so its last item has
nothing to pair with, as in `(let (width 3 height) ...)` or
`(loop (count) ...)`.

The compiler counts the items alone, so a list such as `((width 3))`, whose one
item is a name and a value in their own parentheses, reports this error too. A
list with an even number of items that writes each name and its value in their
own parentheses reports `L0336` instead.

A form with this error and no body reports this error, not `L0335`.

## Erroneous example

```lisp
(defn main ()
  (let (width 3 height)
    (println (* width height))))
```

## Fixes

Bind `height` to 4:

```lisp
(defn main ()
  (let (width 3 height 4)
    (println (* width height))))
```

Or remove the name that has no value:

```lisp
(defn main ()
  (let (width 3)
    (println (* width width))))
```
