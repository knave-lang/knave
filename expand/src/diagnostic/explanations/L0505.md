knave takes a `type` signature as written. A type parameter that it declares,
such as `a` in `(where (a) ...)`, stands for any type, `Copy` or not, unless the
signature gives it a bound such as `copy`. This function uses a parameter of
such a type after a move, and only a `Copy` value can be used again after it
moves.

Without a written signature, knave infers the `copy` bound itself. A use after a
move of a value of a concrete type, or of a local, reports `L0501` instead.

## Erroneous example

```knave
(type twice
  (where (a) (fn (a) (vec a))))

(defn twice (x) (vec x x))

(defn main () (println (len (twice 3))))
```

## Fixes

Give the type parameter the `copy` bound:

```knave
(type twice
  (where ((a copy)) (fn (a) (vec a))))

(defn twice (x) (vec x x))

(defn main () (println (len (twice 3))))
```

Or give it the `clone` bound and clone the value, which also accepts types that
are not `Copy`:

```knave
(type twice
  (where ((a clone)) (fn (a) (vec a))))

(defn twice (x) (vec (clone x) x))

(defn main () (println (len (twice (str "hi")))))
```
