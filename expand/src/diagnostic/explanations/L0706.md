The value of `:edition` in a project file is a whole number, the value of
`:features` is a list of strings, and the value of every other key is a string.
This error reports a value of another kind, such as `:entry src/main.knv`
without quotes, `:version 1`, `:edition "2026"`, or a feature written as a bare
name in `:features (derive)`. In a library entry that already reports `L0712`,
`L0713` or `L0714`, the compiler does not check the kind of `:path`, `:git` or
`:rev`.

The compiler reports each such mistake in the file, not only the first, except
as above. Every command that reads the project reports it, run in the project's
folder or below it, or given a file there: `knave check`, `types`, `lint`,
`expand`, `emit`, `build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`,
`add` and `remove`. `knave fmt` reports it as a warning and formats the files
all the same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter :entry src/main.knv)
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Quote the path:

```knave
;; project.knv
(defproject greeter :entry "src/main.knv")
;; src/main.knv
(defn main ()
  (println "hello"))
```
