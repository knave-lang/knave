A library comes from a folder, named by `:path`, or from a commit of a git
repository, named by `:git` and `:rev`, and one entry names one of them. This
error reports a library entry with `:path` and also `:git` or `:rev`.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter
  (libraries
    (hints :path "hints" :git "https://example.com/hints.git")))
;; src/main.knv
(use hints hint)

(defn main () (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```

## Fixes

Keep the folder, when the library's files are on disk:

```knave
;; project.knv
(defproject greeter (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main () (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
