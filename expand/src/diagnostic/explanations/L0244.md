A symbol made of `:` and a field name, such as `:year`, is a field keyword. A
`let` binding, a `fn` parameter, a `def`, a binder in a `match` pattern and the
name that a definer such as `defstruct` defines are all this error when they use
one as the name.

Two places take a keyword without binding it. A `defn` parameter list that
starts with a keyword declares keyword parameters, and the body names each one
without its `:`. Inside a variant pattern, a keyword labels the field that the
next pattern matches, and a variant with no such field reports `L0460`.

## Erroneous example

```lisp
(defstruct car :make string :year u16)

(defn main ()
  (let (car (->car :make (str "Nissan") :year 2024)
        :year (:year car))
    (println :year)))
```

## Fixes

Bind the value to a plain name:

```lisp
(defstruct car :make string :year u16)

(defn main ()
  (let (car (->car :make (str "Nissan") :year 2024)
        year (:year car))
    (println year)))
```
