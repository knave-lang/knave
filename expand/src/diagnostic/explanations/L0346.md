`defenum` reads each form after the enum's name, its docstring and its `rust`
clause as a variant, and takes the variant's name from the symbol that the form
is or starts with. This error reports a variant with no such symbol, where a
keyword does not count as a symbol. Such a variant is, for example, a keyword
such as `:square`, a number, a string, an empty list, or a list headed by a
keyword, a number or another list, such as `(:circle f64)` or `((circle) f64)`.

A string right after the enum's name is its docstring, so only a string in a
later place reports this error. A `rust` clause after a variant reports `L0340`
before any variant is checked.

## Erroneous example

```lisp
(defenum shape (circle f64) :square)

(defn area (item)
  (match item
    ((circle radius) (* radius radius))
    (square 1.0)))

(defn main () (println (area (shape/circle 2.0))))
```

## Fixes

Write the variant as a bare name:

```lisp
(defenum shape (circle f64) square)

(defn area (item)
  (match item
    ((circle radius) (* radius radius))
    (square 1.0)))

(defn main () (println (area (shape/circle 2.0))))
```
