Each built-in of the `code` module takes arguments of particular kinds, such
as a symbol for `symbol-name`, a string for `string-length`, a list for `len`,
code for `first`, an index from zero up for `nth`, and a list of strings for
`distinct-leading-lines`. Macro code that passes a value of another kind
reports this error, such as a number that a macro passes on from its input.
The error points at the call of the built-in, or at the item of a list that
is not a string.

A built-in called with too few or too many arguments reports `L0311` instead,
and an `nth` index past the end of its list reports `L0314`.

## Erroneous example

```lisp
(use code symbol-name)

(defmacro name-text (name)
  (symbol-name name))

(defn main ()
  (println (name-text 5)))
```

## Fixes

Pass `name-text` a symbol:

```lisp
(use code symbol-name)

(defmacro name-text (name)
  (symbol-name name))

(defn main ()
  (println (name-text total)))
```

When the macro takes any form, test the form's kind before reading it:

```lisp
(use code symbol? symbol-name)

(defmacro name-text (name)
  (if (symbol? name)
    (symbol-name name)
    (quote "not a name")))

(defn main ()
  (println (name-text 5)))
```
