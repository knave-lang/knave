A `local` binds a name for the forms that follow it in the same body: a
function's, a `do`'s, or one that a macro such as `let` or `when` builds.
This error reports a `local` elsewhere, where no later form could see the
name: an argument of a call, a branch of an `if`, or the value of a
module-level `def`.

## Erroneous example

```lisp
(defn describe (n)
  (if (> n 0)
    (local label "positive")
    (local label "not positive"))
  label)

(defn main ()
  (println (describe 3)))
```

## Fixes

Bind the name once, and choose its value with the `if`:

```lisp
(defn describe (n)
  (let (label (if (> n 0) "positive" "not positive"))
    label))

(defn main ()
  (println (describe 3)))
```

In a single expression:

```lisp
(defn main ()
  (println (let (total (+ 1 2)) total)))
```
