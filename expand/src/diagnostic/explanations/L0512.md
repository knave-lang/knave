A closure cannot declare a lifetime, so knave gives a borrowed parameter of a
`local` closure the enclosing function's shared lifetime, or `'static` when the
function has none, as `main` has none. When the closure's result can borrow from
that parameter, its argument must live at least that long.

This call passes a borrow of a value that the enclosing function owns: a
`local`, a temporary such as `(vec 2019 2021)`, or a parameter that owns its
value. knave checks, inside a function, calls to a closure bound by a `local`
with no written type, directly or through another `local`, whose result can
borrow from the parameter.

## Erroneous example

```knave
(defn main ()
  (local years (vec 2019 2021))
  (local first
    (fn ((items (ref (vec i64))))
      (at items 0)))
  (println (first years)))
```

## Fixes

Define the function with `defn`, where the result may borrow from its argument:

```knave
(defn first (items) (at items 0))

(defn main ()
  (local years (vec 2019 2021))
  (println (first years)))
```

Or let the closure capture the value instead of taking it as an argument:

```knave
(defn main ()
  (local years (vec 2019 2021))
  (local first (fn () (at years 0)))
  (println (first)))
```
