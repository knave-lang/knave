A library may list libraries of its own in its project file, and a `use` path
that starts with the name of any library of the build, such as `keymap` or
`keymap/extra`, names that library. The program can load only the libraries
that its own project file lists. This error reports a `use` in the program
whose path starts with the name of a library that only other libraries list.

A path whose head names no library at all reports `L0204` instead, and so does
a `use` in a library's module of a library that this library does not list.
When the program also has a module file or a folder of the library's name, such
as `keymap.knv` or `keymap/` at the source root, the same `use` reports `L0253`.

## Erroneous example

```lisp
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout)
(use keymap key)

(defn main ()
  (println (shout key)))
;; libs/hints/project.knv
(defproject hints (libraries (keymap :path "../keymap")))
;; libs/hints/src/lib.knv
(use keymap key)

(export shout)

(defn shout (text) (str text key "!"))
;; libs/keymap/project.knv
(defproject keymap)
;; libs/keymap/src/lib.knv
(export key)

(def key "k")
```

## Fixes

Export the name from `hints`, which lists `keymap`, and import it from there:

```lisp
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout key)

(defn main ()
  (println (shout key)))
;; libs/hints/project.knv
(defproject hints (libraries (keymap :path "../keymap")))
;; libs/hints/src/lib.knv
(use keymap key)

(export shout key)

(defn shout (text) (str text key "!"))
;; libs/keymap/project.knv
(defproject keymap)
;; libs/keymap/src/lib.knv
(export key)

(def key "k")
```

Or depend on `keymap` from the program itself:

```lisp
;; project.knv
(defproject app
  (libraries (hints :path "libs/hints") (keymap :path "libs/keymap")))
;; src/main.knv
(use hints shout)
(use keymap key)

(defn main ()
  (println (shout key)))
;; libs/hints/project.knv
(defproject hints (libraries (keymap :path "../keymap")))
;; libs/hints/src/lib.knv
(use keymap key)

(export shout)

(defn shout (text) (str text key "!"))
;; libs/keymap/project.knv
(defproject keymap)
;; libs/keymap/src/lib.knv
(export key)

(def key "k")
```
