The `:code` part of a description names the diagnostic that `fail` or `warn`
reports, by a name such as `repeated-parameter` for `L0320`: the name of the
code in the compiler, in lowercase, with `-` in place of each `_`. `fail` takes
the name of a macro-stage diagnostic, whose code starts with `L03`, and `warn`
takes the name of a lint, whose code starts with `L08`, such as
`unmatched-link`.

This error reports a `:code` symbol that is not such a name, such as a
misspelled name, a name written with `_`, the code itself, such as `L0320`, or
the name of a diagnostic of another stage, such as `repeated-field` in a `fail`
or `repeated-parameter` in a `warn`. The compiler reads the name when the call
runs, so a macro reports this error only from a call that reaches it. A
`:code` value that is not a symbol, such as a string, reports `L0321` instead.

## Erroneous example

```knave
(use code warn)

(defmacro placeholder (page)
  (warn "this link is a placeholder" page (quote (:code unmatched-lnk)))
  page)

(defn main () (println (placeholder "home")))
```

## Fixes

Spell the name of the lint in full:

```knave
(use code warn)

(defmacro placeholder (page)
  (warn "this link is a placeholder" page (quote (:code unmatched-link)))
  page)

(defn main () (println (placeholder "home")))
```
