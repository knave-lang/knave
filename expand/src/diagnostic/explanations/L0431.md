A case pattern in parentheses without its enum's name, such as `(triangle
side)` or `(blank)`, names a case of the enum that the matched value has.
This error reports such a pattern, at any depth, when the compiler knows that
enum and none of its cases carries the name, though a case of another enum
does. The compiler knows the enum from a `type` signature, from the value, or
from an earlier arm of the same `match`. The enums include the prelude's, so
`(ok n)` against an `option` reports it.

A bare name without parentheses, such as `blank`, that is a case of another
enum binds a new name that matches any value instead. A name in parentheses that
no enum has as a case reports `L0231`, and a case written with another
enum's name, as in `marker/triangle`, reports `L0401`, as does a case pattern
against a value that is not an enum.

## Erroneous example

```knave
(defenum shape
  (circle float)
  (square float))

(defenum marker (triangle float))

(type size (fn (shape) float))

(defn size (s)
  (match s
    ((circle radius) radius)
    ((triangle side) side)
    (_ 0.0)))

(defn main ()
  (println (size (shape/circle 1.0))))
```

## Fixes

Match `square`, the case of `shape` that the arm meant:

```knave
(defenum shape
  (circle float)
  (square float))

(defenum marker (triangle float))

(type size (fn (shape) float))

(defn size (s)
  (match s
    ((circle radius) radius)
    ((square side) side)))

(defn main ()
  (println (size (shape/circle 1.0))))
```

Or match the `marker` in a function of its own:

```knave
(defenum shape
  (circle float)
  (square float))

(defenum marker (triangle float))

(type marker-size (fn (marker) float))

(defn marker-size (m)
  (match m ((triangle side) side)))

(defn main ()
  (println (marker-size (marker/triangle 2.0))))
```
