A task's name is the word that follows `knave task` on a command line, so the
compiler holds it to one spelling. The name must start with a letter from `a`
to `z` and hold only such letters, the digits `0` to `9`, and `-`, with no
`-` at its end and never two in a row. A name such as `tidy-2024` or
`tidy-2up` passes. This error reports any other name, such as `tidyUp`,
`Tidy`, `tidy_up`, `tidy.up`, `tidy/up`, `tidy--up`, `tidy-` or `-tidy`.

The compiler tests the name before it tests where the `deftask` lies, so a
`deftask` outside `tasks/` with such a name reports this error too, under any
command that expands the file.

A name that starts with a digit, such as `2tidy`, is not a symbol, so the
reader reports `L0105` instead, and a keyword name such as `:tidy` reports
`L0301`.

## Erroneous example

```lisp
;; knave task
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/clean.knv
(deftask tidyUp () (println "tidying"))
```

## Fixes

Spell the name in lowercase words with a `-` between them:

```lisp
;; knave task tidy-up
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/clean.knv
(deftask tidy-up () (println "tidying"))
```
