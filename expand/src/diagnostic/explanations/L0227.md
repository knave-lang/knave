A `local` binds a name for the forms that follow it in the same body: a
function's, a `do`'s, or one that a macro such as `let` or `when` builds. This
error reports a `local` anywhere else, where no later form could see the name,
such as an argument of a call, the test or a branch of an `if`, a binding's
value in a `let`, or the value of a module-level `def`.

## Erroneous example

```knave
(defn describe (n)
  (if (> n 0)
    (local label "positive")
    (local label "not positive"))
  label)

(defn main ()
  (println (describe 3)))
```

## Fixes

Bind the name once, and choose its value with the `if`:

```knave
(defn describe (n)
  (let (label (if (> n 0) "positive" "not positive"))
    label))

(defn main ()
  (println (describe 3)))
```

In a single expression:

```knave
(defn main ()
  (println (let (total (+ 1 2)) total)))
```
