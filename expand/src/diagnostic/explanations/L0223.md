A `deftype` or a `rust-type` can list clauses after its template. Each clause
pairs a type with a template of its own, used in place of the main one when the
type's argument is that type. A clause chooses by the type's single argument, so
a head with no parameters, as a plain name or `(pair)`, or with two or more
reports this error.

## Erroneous example

```knave
(deftype (pair left right)
  (rust "({0}, {1})")
  (u8 "[u8; 2]"))

(def make-pair
  (rust "({0}, {1})"
    (where (a b) (fn (a b) (pair a b)))))

(def left-of
  (rust "{0}.0"
    (where (a b) (fn ((pair a b)) a))))

(defn main ()
  (println (left-of (make-pair 4 "four"))))
```

## Fixes

Drop the clause, and let every pair use the main template:

```knave
(deftype (pair left right) (rust "({0}, {1})"))

(def make-pair
  (rust "({0}, {1})"
    (where (a b) (fn (a b) (pair a b)))))

(def left-of
  (rust "{0}.0"
    (where (a b) (fn ((pair a b)) a))))

(defn main ()
  (println (left-of (make-pair 4 "four"))))
```

When both halves always share one type, a type of one parameter keeps the
clause:

```knave
(deftype (twin item)
  (rust "({0}, {0})")
  (u8 "[u8; 2]"))

(def make-twin
  (rust "({0}, {0})"
    (where (a) (fn (a) (twin a)))
    (u8 "[{0}, {0}]")))

(def left-of
  (rust "<[_; 2]>::from({0})[0]"
    (where (a) (fn ((twin a)) a))))

(defn main ()
  (println (left-of (make-twin 4)))
  (println (left-of (make-twin (the u8 9)))))
```
