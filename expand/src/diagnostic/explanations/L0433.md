A `match` gives a value for every value its subject can hold. When the subject
is an enum, the arms together must cover each variant. This `match` has no arm
for at least one variant, so some values would reach no arm. The diagnostic
lists the cases that no arm covers.

## Erroneous example

```lisp
(defenum shape (circle f64) (rect f64 f64) point)

(defn area (s)
  (match s
    ((circle r) (* 3.0 r r))
    (point 0.0)))

(defn main ()
  (println (area shape/point)))
```

## Fixes

Add an arm for each case that is not covered:

```lisp
(defenum shape (circle f64) (rect f64 f64) point)

(defn area (s)
  (match s
    ((circle r) (* 3.0 r r))
    ((rect width height) (* width height))
    (point 0.0)))

(defn main ()
  (println (area shape/point)))
```

Or end with a `_` arm, which matches every value that the arms above it do not:

```lisp
(defenum shape (circle f64) (rect f64 f64) point)

(defn area (s)
  (match s
    ((circle r) (* 3.0 r r))
    (_ 0.0)))

(defn main ()
  (println (area shape/point)))
```
