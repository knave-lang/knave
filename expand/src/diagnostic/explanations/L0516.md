A function that changes a parameter receives it as a mutable borrow, and Rust
allows one mutable borrow of a value at a time. This call changes two of its
arguments, and both name the same value: the same local twice, the same field
twice, or a whole value and a field inside it.

An argument counts as changed when it is written `(mut place)`, or when its
parameter is `mut`, inferred from the callee's body or written in a signature.
Two different fields of one value do not overlap, and an argument that the
callee only reads may name the same value as a changed one.

## Erroneous example

```lisp
(defn add-into! (total amount)
  (set! total (+ total amount))
  (set! amount 0))

(defn main ()
  (local sum 5)
  (add-into! sum sum)
  (println sum))
```

## Fixes

Give each changed argument its own place:

```lisp
(defn add-into! (total amount)
  (set! total (+ total amount))
  (set! amount 0))

(defn main ()
  (local sum 5)
  (local extra sum)
  (add-into! sum extra)
  (println sum)
  (println extra))
```

For a value that is not `Copy`, give the second place a `clone`:

```lisp
(defn grow-both! (left right)
  (push! left 1)
  (push! right 2))

(defn main ()
  (local scores (vec 0))
  (local copy (clone scores))
  (grow-both! scores copy)
  (println (len scores))
  (println (len copy)))
```
