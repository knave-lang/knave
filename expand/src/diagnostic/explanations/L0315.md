`number-add` and `number-sub` of the `code` module compute with 128-bit
signed integers. This error reports a call whose result lies outside that
range, which runs from -170141183460469231731687303715884105728 to
170141183460469231731687303715884105727. The call may stand in a macro body,
in a function that a macro calls, or in a `def` whose value macro code reads.

A number literal past that range reports `L0107` instead.

## Erroneous example

```lisp
(use code number-add)

(defmacro past-the-limit ()
  (number-add 170141183460469231731687303715884105727 1))

(defn main ()
  (println (past-the-limit)))
```

## Fixes

Keep the numbers that macro code adds within the range:

```lisp
(use code number-add)

(defmacro answer ()
  (number-add 41 1))

(defn main ()
  (println (answer)))
```
