`let`, `loop`, `let-try` and `let-match` read the item right after their name as
one list that holds each name followed by its value, as in `(let (width 3 height
4) ...)`. This error reports a form whose item there is not written that way. It
covers three cases:

- nothing follows the form's name, as in `(let)`;
- the item after the name is not a list, such as `(let x 5 ...)` or `(let 5
  ...)`;
- the list has an even number of items, and an item in a name's place is a list
  of two items whose second item is a number, a string, `true` or `false`, as
  `(width 3)` is in `((width 3) (height 4))`.

In the third case, `(width x)` stays a name with its type, because its second
item is not a literal, and in `let-match` the list counts only when its head is
a plain name: a list whose head names a struct or a variant, such as `(meters
5)`, is read as a pattern, and a list whose head is not a name, such as `("a"
1)`, reports `L0231`. A list with an odd number of items reports `L0334`
instead, as `((width 3))` does.

## Erroneous example

```knave
(defn main ()
  (let ((width 3) (height 4))
    (println (* width height))))
```

## Fixes

Remove the inner parentheses:

```knave
(defn main ()
  (let (width 3 height 4)
    (println (* width height))))
```
