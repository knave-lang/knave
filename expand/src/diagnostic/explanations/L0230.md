In the kernel `enum` form, a variant written as `(labeled (struct ...))` takes
named fields from its `struct` body, and that body must stand alone after the
variant's name. A variant that puts a `struct` body beside a type, or beside a
second `struct` body, is this error. `defenum` writes a variant's fields flat,
as in `(labeled :text string :size f64)`, and reports its own errors for a
variant that mixes the two, so this error comes from `enum` written directly.

## Erroneous example

```lisp
(enum shape
  (circle f64)
  (labeled (struct (text string)) f64))

(defn main ()
  (local tag (shape/labeled (str "box") 2.0))
  (match tag
    ((shape/labeled text size) (println text " " size))
    ((shape/circle radius) (println radius))))
```

## Fixes

Move every field into the `struct` body:

```lisp
(enum shape
  (circle f64)
  (labeled (struct (text string) (size f64))))

(defn main ()
  (local tag (shape/labeled (str "box") 2.0))
  (match tag
    ((shape/labeled text size) (println text " " size))
    ((shape/circle radius) (println radius))))
```

Or write every part as a type:

```lisp
(enum shape
  (circle f64)
  (labeled string f64))

(defn main ()
  (local tag (shape/labeled (str "box") 2.0))
  (match tag
    ((shape/labeled text size) (println text " " size))
    ((shape/circle radius) (println radius))))
```
