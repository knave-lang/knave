`knave lint` runs each lint rule once on each definition of the program's own
modules, under a limit of 30,000,000 steps, the default limit of a top-level
form's macro calls. This warning reports a definition on which one or more
rules passed that limit. Those rules stop on that definition, and the warning
names each of them, labeled at the definition. The other rules still check the
definition, and the skipped rules still check every other definition.

Only `knave lint` runs the rules, so only it reports this warning. It is a lint,
so `knave lint` exits with status 1.

## Described example

No definition of a size to show takes a rule past the limit, so the
explanation tests run no example here. A function whose body binds 10,000
names, all read, still passes every rule.

## Fixes

Split the definition into several smaller definitions, so that each rule checks
each one within the limit.
