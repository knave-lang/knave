A `rust` form's template is Rust text in which `{0}` stands for the first
argument, `{1}` for the second, and so on. This error reports a placeholder that
the template cannot read: a `{` that never closes, as in `{0 * 2`, a `}` that no
`{` opens, as in `count({0}}`, a `{}` with nothing inside, as Rust's own
`format!("{}", x)` writes, a name after `&` or `owned`, as in `{&name}` or
`{owned name}`, or a binder with no name or with `&` or `owned`, as in `{!}`,
`{&!x}` or `{owned !x}`, or a conversion with a name, `&` or `owned`, as in
`{index name}` or `{&index 0}`. The check covers the template that follows
`rust` and each `(type "template")` clause after the form's type. Only the
template that follows `rust` may convert a placeholder, so `{index 0}` in a
clause, or in the template of a `deftype`, a `rust-type` or an enum, is this
error too. The type stage
reports it too for `{index 0}` or `{index? 0}` at a parameter that is not `int`,
and for `{index? 0}` in a template that does not return an option.

## Erroneous example

```knave
(def double
  (rust "{0 * 2" (fn (i64) i64)))

(defn main () (println (double 21)))
```

## Fixes

Close the placeholder:

```knave
(def double
  (rust "{0} * 2" (fn (i64) i64)))

(defn main () (println (double 21)))
```

With a format string:

```knave
(def bracketed
  (rust "format!(\"{{}}\", {0})" (fn (i64) string)))

(defn main () (println (bracketed 5)))
```
