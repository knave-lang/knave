After the shape, `header-shape` takes the keywords `:docstring`,
`:one-per-line`, `:arms` and `:bindings`, in any order. This error reports
any other form in that place, such as a misspelled keyword, another keyword,
a plain symbol such as `docstring`, or a list, and one of those four keywords
written a second time.

A shape that is not a list headed by a symbol reports `L0329` first.

## Erroneous example

```lisp
(use prelude/macros header-shape)

(defmacro twice (x) (template (* 2 (unquote x))))

(header-shape (twice x) :docstrings)

(defn main () (println (twice 2)))
```

## Fixes

Spell the keyword as `header-shape` knows it:

```lisp
(use prelude/macros header-shape)

(defmacro twice (x) (template (* 2 (unquote x))))

(header-shape (twice x) :docstring)

(defn main () (println (twice 2)))
```

Or state the shape alone:

```lisp
(use prelude/macros header-shape)

(defmacro twice (x) (template (* 2 (unquote x))))

(header-shape (twice x))

(defn main () (println (twice 2)))
```
