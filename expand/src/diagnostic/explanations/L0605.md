A trait signature cannot name the lifetime of a type that holds a borrow, such
as a struct with a `str` field or an enum with a `(ref str)` payload. This error
reports a method, in an `impl` of a trait for such a type, whose result would
need that lifetime from an argument that the trait's signature does not let it
come from. It reports three cases:

- The result's only borrows are the implementor's, as when the result is `self`
  or holds it, such as `(option self)`, and an argument that the trait does not
  write as `self` reaches the result. That argument may have the implementor's
  type written by name, such as `car` beside `self`, or be a borrow, such as a
  `(ref str)` used to build the result.
- The signature's parameters are all values with no borrow in their types, such
  as `self` and `i64`, and its result is a borrow. An argument's borrow, such as
  a `str` field of `self`, reaches that result.
- A `self` taken by value reaches a borrowed result, such as a `str` field of
  `self` returned from `(fn (self (ref str)) (ref str))`, and no parameter of
  the signature is a reference to `self`.

An argument reaches the result through forms such as a local, an `if`, a `some`,
a struct that the body builds, a `match` arm that returns one of its bindings,
or a call of a function whose result borrows from that argument. A call that
returns only another argument does not reach it, and neither does a `match`
whose arms return none of their bindings. A `(ref self)` parameter beside a
by-value `self` lets the result borrow from both. A type that holds no borrow,
such as a struct with a `string` field, never reports this error. In the third
case, a call of a closure counts as reaching nothing, so rustc reports what it
rejects there as `L0604`.

## Erroneous example

```lisp
(defstruct car :model str :year i64)

(trait named (model-of (fn (self) (ref str))))

(impl named car (model-of (c) (:model c)))

(defn main () (println (model-of (->car "Leaf" 2024))))
```

## Fixes

Give the method a reference receiver, which Rust lets the result borrow
through:

```lisp
(defstruct car :model str :year i64)

(trait named (model-of (fn ((ref self)) (ref str))))

(impl named car (model-of (c) (:model c)))

(defn main () (println (model-of (->car "Leaf" 2024))))
```

Or read the field in a function outside the trait, whose signature the
compiler infers with its lifetime:

```lisp
(defstruct car :model str :year i64)

(defn model-of (c) (:model c))

(defn main () (println (model-of (->car "Leaf" 2024))))
```
