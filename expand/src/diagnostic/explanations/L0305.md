A macro call expands to a form, and when that form is another macro call, the
expander expands it too. This error reports a call where that chain reaches
256 expansions, such as a rule that rewrites a call into a call of the same
macro, or two rules that rewrite into each other. Expansions nested inside
one another count toward the same limit, so a rule that puts its own call
inside an argument, such as an argument of `+`, reports this error too. It
applies to a call inside a function and to a call at the top level of a
module.

A rule that puts its own call inside a `do` reports `L0325` instead.

## Erroneous example

```lisp
(defn larger (left right)
  (if (> left right) left right))

(defrule larger-flipped
  ((left right) (larger-flipped right left)))

(defn main ()
  (println (larger-flipped 3 4)))
```

## Fixes

Expand to a call of the function:

```lisp
(defn larger (left right)
  (if (> left right) left right))

(defrule larger-flipped
  ((left right) (larger right left)))

(defn main ()
  (println (larger-flipped 3 4)))
```
