`(macro (form) body ...)` builds a macro, code that the compiler runs while it
expands the program. The compiler registers a macro only from a top-level `def`
that binds the `macro` form itself, so the macro exists before any form that
calls it. As an expression anywhere else, the form is this error: bound by `let`
or `local` in a function body, returned by a function, or nested inside another
value, even a value that a module-level `def` binds.

## Erroneous example

```knave
(use code first rest)

(defn main ()
  (let (twice (macro (form)
                (let (action (first (rest form)))
                  (template (do (unquote action) (unquote action))))))
    (twice (println "hi"))))
```

## Fixes

Move the macro out of `main`:

```knave
(use code first rest)

(def twice
  (macro (form)
    (let (action (first (rest form)))
      (template (do (unquote action) (unquote action))))))

(defn main () (twice (println "hi")))
```

`defmacro` writes the same definition and names the macro's parameters:

```knave
(defmacro twice (form)
  (template (do (unquote form) (unquote form))))

(defn main () (twice (println "hi")))
```
