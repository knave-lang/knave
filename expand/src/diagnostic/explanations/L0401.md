Every value has one type, and each place that takes a value expects a type: a
parameter, an operand of an arithmetic call, a `local` with a type, or a
function's result. The value given here has a different type from the one the
place expects. knave never converts a value of one number type to another, so
an `i64` value does not become an `f64`.

## Erroneous example

```knave
(defn main ()
  (local (width i64) 2)
  (println (* width 1.5)))
```

`width` is an `i64`, and `1.5` is a float, so `*` gets two types.

## Fixes

Give both operands the same type:

```knave
(defn main ()
  (local (width f64) 2.0)
  (println (* width 1.5)))
```

Or keep the integer and multiply by an integer:

```knave
(defn main ()
  (local (width i64) 2)
  (println (* width 3)))
```
