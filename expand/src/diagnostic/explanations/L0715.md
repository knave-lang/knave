A library from a git repository names its commit with `:rev`. This error reports
a `:rev` string that is not 40 hexadecimal digits, such as a short hash like
`"0123abc"`, a branch name like `"main"`, or a tag.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter
  (libraries
    (hints :git "https://example.com/hints.git" :rev "0123abc")))
;; src/main.knv
(use hints hint)

(defn main () (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```

## Fixes

When the library's files are on disk, name their folder with `:path` instead:

```knave
;; project.knv
(defproject greeter (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main () (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
