A `defenum` case whose first item after the name is a keyword holds
`:field type` pairs, such as `(labeled :text string :size float)`. Any other
case holds a list of types, such as `(labeled string float)`.

This error reports a case that mixes the two: a keyword among the items of
a case that starts with a type, such as `(labeled string :size float)`, or an
item that is not a keyword in the place of the next field of a case that
starts with a keyword, such as `float` in `(labeled :text string float)`. The items
are checked in order, so in a case that starts with a type, a `struct` list
before the keyword reports `L0347` instead.

A field keyword followed by another keyword or by nothing reports `L0349`.

## Erroneous example

```knave
(defenum shape
  (labeled string :size float)
  dot)

(defn main ()
  (match (shape/labeled (str "note") 2.0)
    ((labeled text _) (println text))
    (dot (println "dot"))))
```

## Fixes

Remove `:size`, so that both items are types:

```knave
(defenum shape
  (labeled string float)
  dot)

(defn main ()
  (match (shape/labeled (str "note") 2.0)
    ((labeled text _) (println text))
    (dot (println "dot"))))
```

Or put `:text` before `string`:

```knave
(defenum shape
  (labeled :text string :size float)
  dot)

(defn main ()
  (match (shape/labeled (str "note") 2.0)
    ((labeled text _) (println text))
    (dot (println "dot"))))
```
