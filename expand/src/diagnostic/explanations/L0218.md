A `rust` form's template is Rust text in which `{0}` stands for the first
argument, `{1}` for the second, and so on. This error reports a placeholder that
the template cannot read: a `{` that never closes, as in `{0 * 2`, a `{}` with
nothing inside, as Rust's own `format!("{}", x)` writes, a name after `&` or
`owned`, as in `{&name}` or `{owned name}`, or a binder with no name or with `&`
or `owned`, as in `{!}`, `{&!x}` or `{owned !x}`. The check covers the template
that follows `rust` and each `(type "template")` clause after the form's type.

## Erroneous example

```knave
(def double
  (rust "{0 * 2" (fn (i64) i64)))

(defn main () (println (double 21)))
```

## Fixes

Close the placeholder:

```knave
(def double
  (rust "{0} * 2" (fn (i64) i64)))

(defn main () (println (double 21)))
```

With a format string:

```knave
(def bracketed
  (rust "format!(\"{{}}\", {0})" (fn (i64) string)))

(defn main () (println (bracketed 5)))
```
