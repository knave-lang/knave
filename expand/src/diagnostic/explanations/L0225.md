The numbered placeholders of a type template count the parameters in the
type's head from zero: `{0}` is the first and `{1}` the second. A placeholder
whose number reaches past the last parameter is this error. It shows when the
head is a plain name with no parameters, as in
`(deftype boxed (rust "Box<{0}>"))`, and when the numbering starts at one. The
check covers the template after the name in a `deftype` or a `rust-type`, and
the type template in a `defenum`'s `(rust "...")` clause.

## Erroneous example

```lisp
(deftype boxed (rust "Box<{0}>"))

(def box-new
  (rust "Box::new({0})" (where (a) (fn (a) (boxed a)))))

(def unbox
  (rust "*{0}" (where (a) (fn ((boxed a)) a))))

(defn main ()
  (println (unbox (box-new 7))))
```

## Fixes

With `item` in the head, `{0}` stands for it:

```lisp
(deftype (boxed item) (rust "Box<{0}>"))

(def box-new
  (rust "Box::new({0})" (where (a) (fn (a) (boxed a)))))

(def unbox
  (rust "*{0}" (where (a) (fn ((boxed a)) a))))

(defn main ()
  (println (unbox (box-new 7))))
```

A template that numbers from one, as `"({1}, {2})"`, numbers from zero
instead:

```lisp
(deftype (pair left right) (rust "({0}, {1})"))

(def make-pair
  (rust "({0}, {1})"
    (where (a b) (fn (a b) (pair a b)))))

(def left-of
  (rust "{0}.0"
    (where (a b) (fn ((pair a b)) a))))

(defn main ()
  (println (left-of (make-pair 4 "four"))))
```
