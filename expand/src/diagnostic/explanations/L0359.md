`deftask` defines a command of a project, which `knave task` runs, and a project
keeps its tasks in the `tasks` directory at its root. This error reports a
`deftask` in any other file, such as a file that `knave check` or `knave run`
reads on its own, even one inside a folder named `tasks`, as well as the entry
module of a project and every module it uses outside `tasks`, such as a helper
under `src`.

The compiler checks the task's shape and its name first, so a `deftask` with a
name that is not kebab-case reports `L0357` instead, wherever it lies, and one
with a keyword for its name reports `L0301`.

## Erroneous example

```lisp
(deftask greet () (println "hello"))

(defn main () (greet))
```

## Fixes

Write the code as a function that `main` calls:

```lisp
(defn greet () (println "hello"))

(defn main () (greet))
```
