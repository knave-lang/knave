Each variant of an `enum` is a symbol, or a list whose head is a symbol
followed by the payload's types. The symbol becomes the variant's name. In this
`enum`, a variant's list starts with something else: a number, a string or a
list, as in `(5 f64)` or `((circle) f64)`.

`defenum` checks its variants before the `enum` it writes, so the same mistake
in a `defenum` reports `L0346` instead.

## Erroneous example

```lisp
(enum shape ("circle" f64) point)

(defn main ()
  (println "shapes"))
```

## Fixes

Start the variant with a symbol:

```lisp
(enum shape (circle f64) point)

(defn main ()
  (match (shape/circle 2.0)
    ((circle radius) (println radius))
    (point (println "point"))))
```
