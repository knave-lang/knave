When a function changes a value that its caller passed in, and its name does
not end with `!`, this warning reports the function. A function changes an
argument when it calls a function that changes the argument in place, such as
`push!`, or when it gives a parameter a new value with `set!`. A function that
passes its parameter on to such a function changes it too, so the warning
reports both functions.

A `!` at the end of a name tells the caller that the call changes its value, so
the language asks for it on every such function. Every command that checks the
program prints the warning: `knave check`, `knave build`, `knave run`,
`knave emit`, `knave types`, `knave test`, `knave repl`, `knave lint` and
`knave doc --types`. `knave doc --write` checks each module's types too, but
prints no warning of that check. The program still builds and runs, and only
`knave lint` exits with status 1 because of it.

## Erroneous example

```knave
(defn add-one (items) (push! items 1))

(defn main ()
  (let (items (vec 1))
    (add-one items)
    (println (len items))))
```

## Fixes

End the name with `!`, and call it by that name:

```knave
(defn add-one! (items) (push! items 1))

(defn main ()
  (let (items (vec 1))
    (add-one! items)
    (println (len items))))
```

Or change a copy that the function owns, and return it:

```knave
(defn with-one (items)
  (let (copy (clone items))
    (push! copy 1)
    copy))

(defn main ()
  (let (items (vec 1))
    (println (len (with-one items)))))
```

For a `set!` of a whole parameter, rebind the parameter with `let` first, so
that the change stays inside the function:

```knave
(defn doubled (total)
  (let (total total)
    (set! total (* total 2))
    total))

(defn main () (println (doubled 2)))
```
