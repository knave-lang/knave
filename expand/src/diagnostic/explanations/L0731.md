This error reports a lint that the `lints` section of `project.knv` lists twice. Each lint takes one entry, so one level holds for it everywhere.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter
  (lints (unused-binding allow) (unused-binding deny)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Keep one entry:

```knave
;; project.knv
(defproject greeter (lints (unused-binding deny)))
;; src/main.knv
(defn main () (println "hello"))
```
