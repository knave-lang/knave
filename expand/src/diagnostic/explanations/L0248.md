A `structural` clause in a `rust-trait`, or in a `deftrait` with a `rust` path,
states as Rust text the impl that the compiler infers for each struct and enum.
Every way that the clause cannot state one impl is this error.

The clause gives the body of the trait's method. A trait with no method or with
two methods is this error, and so is a method whose first parameter is an owned
`self`, a `(mut self)` or a borrow of another type. A second `structural` clause
in one trait is this error too.

The trait's Rust path must not be a Rust trait that `derive` produces, such as
`std::clone::Clone`, and no other trait in scope may bind the same path, whether
the prelude defines it, as `number` binds `crate::rt::Number`, or the program
does. Two traits that cannot see each other, such as traits in two modules,
still may not both give one path a `structural` clause: the second clause the
compiler reads is this error.

The clause is a list of keys, each followed by a template string. It holds each
of `:struct`, `:field`, `:variant`, `:part` and `:bare` exactly once. A key that
is missing, a key given twice, a key outside that list and an item that is not a
key at all, such as a string, are this error, and so is a key followed by a
symbol or by nothing. Each key fills only its own placeholders: `{field}` in
`:part`, a parameter number past the method's last parameter, and an unclosed
`{name` are all this error.

A plain `trait` takes no `structural` clause, and reads one as a method.

## Erroneous example

```lisp
(rust-type octal-out "std::fmt::Formatter<'_>")

(rust-type octal-result "std::fmt::Result")

(rust-trait octal "std::fmt::Octal"
  (method fmt
    (fn ((ref self) (mut octal-out)) octal-result))
  (structural
    :struct "write!({1}, \"{name}\")"
    :field ""
    :variant "write!({1}, \"{name}\")"
    :part "")
  u32)

(defstruct mode :owner u32)

(def show-octal
  (rust "println!(\"{{:o}}\", {&0})"
    (where ((a octal)) (fn ((ref a)) unit))))

(defn main ()
  (show-octal (->mode 8)))
```

## Fixes

Write the `:bare` text too, which a variant with no payload uses:

```lisp
(rust-type octal-out "std::fmt::Formatter<'_>")

(rust-type octal-result "std::fmt::Result")

(rust-trait octal "std::fmt::Octal"
  (method fmt
    (fn ((ref self) (mut octal-out)) octal-result))
  (structural
    :struct "write!({1}, \"{name}\")"
    :field ""
    :variant "write!({1}, \"{name}\")"
    :part ""
    :bare "write!({1}, \"{name}\")")
  u32)

(defstruct mode :owner u32)

(def show-octal
  (rust "println!(\"{{:o}}\", {&0})"
    (where ((a octal)) (fn ((ref a)) unit))))

(defn main ()
  (show-octal (->mode 8)))
```
