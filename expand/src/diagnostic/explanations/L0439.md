A type parameter of an enum takes its type from the payloads that use it. This
error reports a type parameter that the payloads use only inside the enum's own
type, such as `a` in `(link (chain a))`. The use may sit at any depth inside
that type, as in `(chain (vec a))`, and the type itself may sit inside another
type, such as `(box (chain a))`, `(vec (tree a))` or a function type, in a
positional part or a named field. No payload then fixes the parameter's type.

A parameter that no payload uses at all reports `L0443` instead. The check reads
the parameters in order and reports only the first that fails, as this error or
as `L0443`.

## Erroneous example

```knave
(defenum (chain a)
  (link (chain a))
  end)

(defn main () (println "ready"))
```

## Fixes

Add a part of type `a` to a variant:

```knave
(defenum (chain a)
  (link a (chain a))
  end)

(defn main () (println "ready"))
```

Or drop `a` from the enum's head:

```knave
(defenum chain
  (link chain)
  end)

(defn main () (println "ready"))
```
