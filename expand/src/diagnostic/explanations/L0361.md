This error reports a `deftask` whose body, the forms after its parameter
list, is exactly one form and that form is a string literal. As in `defn`, a
string at the start of a body documents the task only when more forms follow
it. A task's value must be `unit` or a `result`, never text, so the compiler
reports a body of one string before it checks any types.

A body of a string and one more string reports `L0404` on the task's name
instead, because the last string is the task's value. A task with no body at
all does nothing and passes. A `deftask` outside `tasks/` reports `L0359`
first.

## Erroneous example

```lisp
;; knave task greet
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/greet.knv
(deftask greet () "Prints a greeting.")
```

## Fixes

Keep the string as the docstring and print the greeting under it:

```lisp
;; knave task greet
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/greet.knv
(deftask greet ()
  "Prints a greeting."
  (println "hello"))
```

Or print the string itself:

```lisp
;; knave task greet
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/greet.knv
(deftask greet () (println "Prints a greeting."))
```
