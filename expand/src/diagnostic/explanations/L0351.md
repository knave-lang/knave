`document` gives a docstring to a term that its module defines, such as a
function that a user macro writes without one. A module documents only its own
terms, so the head of each `document` header must name a definition of the same
module. This header names something else: an imported name, a kernel form, or
a name that nothing defines. The definition may stand above or below the
`document`.

## Erroneous example

```knave
(use prelude/macros document)

(document (greet name)
  "Says hello to a name.")

(defn main () (println "hello"))
```

## Fixes

Define the term in the same module:

```knave
(use prelude/macros document)

(document (greet name)
  "Says hello to a name.")

(defn greet (name) (println "hello " name))

(defn main () (greet "ada"))
```

Or write the docstring in the definition itself, and drop the `document`:

```knave
(defn greet (name)
  "Says hello to a name."
  (println "hello " name))

(defn main () (greet "ada"))
```
