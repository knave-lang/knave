A duration counts time from zero, so `seconds`, `millis`, `micros` and `nanos`
take a count of zero or more. This error reports a negative number written as
the count. A count that the program computes is checked when it runs: a
negative one panics with the call and its value, as in `(seconds -3)`.

## Erroneous example

```knave
(defn main () (sleep (millis -250)))
```

## Fixes

Write the count without its sign:

```knave
(defn main () (sleep (millis 250)))
```
