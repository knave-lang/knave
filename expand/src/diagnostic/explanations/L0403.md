A call runs the value in its head position with the values after it. This
error reports a call whose head has a type, known when the call is checked,
other than a function type. The head may be any form, such as a name bound to
a number or a string, a literal such as `"text"`, a struct, a vector, or the
result of another call, as in `((five))`. A parameter counts too when a `type`
signature or an earlier use fixes its type, as `(+ x 1)` fixes `x` as a number
before a later `(x 2)`. A borrow of a function, such as `(ref f)`, or an
element that `at` reads from a vector of functions, reports this error as well.

When the head's type is still open at the call, the call makes it a function
type instead, so a later use of that value as a number reports `L0401`.

## Erroneous example

```knave
(defn main ()
  (let (count 3)
    (println (count 2))))
```

## Fixes

Write the operation in the head position, and pass the number to it:

```knave
(defn main ()
  (let (count 3)
    (println (* count 2))))
```

Or bind a function to the name that the call uses:

```knave
(defn main ()
  (let (count (fn (x) (* x 3)))
    (println (count 2))))
```
