Macro code runs while the compiler expands the program, and the values it works
on are forms. This error reports a form in macro code that builds or reads a
value of the program, such as a struct built with `->point`, a field read such
as `(:x form)`, a `try` or `infer` form, an `assoc`, a collection read or change
such as `get`, `keys`, `vals`, `iter` or `push!`, a `set!` of an `at` form, or
an enum variant such as `flag/on`.

The compiler checks the whole macro body when it defines the macro, along with
each function or `def` that the body calls or reads, so a branch that never runs
and a `fn` inside the body report this error too. An enum variant reports it
only when a call of the macro reaches the variant. A form inside `quote` or
`template` is code that the macro returns, so it reports nothing.

A function of the program, such as `at` or `+`, reports `L0306` instead, a
`match` reports `L0317`, and a `rust` form reports `L0319`.

## Erroneous example

```knave
(defstruct point
  :x i64
  :y i64)

(defmacro origin () (->point :x 0 :y 0))

(defn main () (println (:x (origin))))
```

## Fixes

Write the struct into the code that the macro returns:

```knave
(defstruct point
  :x i64
  :y i64)

(defmacro origin ()
  (quote (->point :x 0 :y 0)))

(defn main () (println (:x (origin))))
```

Or drop the macro, and build the struct in a function:

```knave
(defstruct point
  :x i64
  :y i64)

(defn origin () (->point :x 0 :y 0))

(defn main () (println (:x (origin))))
```
