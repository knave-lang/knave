A function that changes a parameter holds the caller's value as a mutable borrow
while the call runs. A closure that the function returns outlives the call,
while the borrow ends with the call, so knave reports a returned closure that
names such a parameter at all, even only to read it.

A parameter counts as changed when the function changes it with `set!`, passes
it to a parameter that changes it, changes it inside the closure, or has a
signature that writes its type as `(mut ...)`. A closure counts as returned when
the function's result holds it in any way: as the last form of the body, a
branch of an `if`, an arm of a `match`, a `loop` that returns it, a local
returned by name, a part of the result such as `(some f)` or an iterator, or a
local closure that a returned closure names. knave checks top-level functions
and methods.

## Erroneous example

```lisp
(defn adder! (x)
  (set! x (+ x 1))
  (fn (y) (+ x y)))

(defn main ()
  (local base 1)
  (local add (adder! base))
  (println (add 10))
  (println base))
```

## Fixes

Copy the changed value into a local, and let the closure use the local:

```lisp
(defn adder! (x)
  (set! x (+ x 1))
  (local value x)
  (fn (y) (+ value y)))

(defn main ()
  (local base 1)
  (local add (adder! base))
  (println (add 10))
  (println base))
```

Or give the closure its own state, and leave the caller's value alone:

```lisp
(defn counter (start)
  (local count start)
  (fn () (set! count (+ count 1)) count))

(defn main ()
  (local laps 0)
  (local next (counter laps))
  (println (next))
  (println (next))
  (println laps))
```
