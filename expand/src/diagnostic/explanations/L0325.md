Expansion can build code deeper than any source file holds. This error reports
code past a fixed depth after expansion: a list expression at depth 1,025 or
more, such as one in the result of a macro that wraps each new call of itself in
a `do`, or a macro result whose lists go more than 1,024 levels down; a form
that top-level `do` forms splice into a module through more than 1,024 levels,
such as a macro that recurses through a top-level `do`; or a list in macro code
whose lists go more than 4,096 levels down, reported at the built-in call, such
as `list`, that makes it, or at the macro call when a prelude function makes it.

A macro that rewrites a call into a call of itself, as the head or as an
argument of a function such as `+`, reports `L0305` instead. A macro whose
expansion grows too large, rather than too deep, reports `L0326`.

## Erroneous example

```knave
(defmacro wrap (value)
  (template (do (wrap (unquote value)))))

(defn main () (println (wrap 1)))
```

## Fixes

Expand to the value inside one `do`, with no further call of the macro:

```knave
(defmacro wrap (value)
  (template (do (unquote value))))

(defn main () (println (wrap 1)))
```
