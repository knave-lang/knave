A `mut` borrow lets the code it goes to change a value where the value lives, so
the value must be a place: a name bound by `let`, `local` or a parameter, or a
field read whose owner is a place, such as `(:x p)`. This error reports a value
that is not a place, such as a call's result, a literal, a top-level `def` or a
`ref` form, at one of two sites:

- inside a written `mut` form, where an `at` read or a `deref` is not a place
  either, as in `(mut (at scores 0))` or `(mut limit)`;
- as the argument of a parameter whose written type is `(mut ...)`, such as the
  vector of `push!`, the target of `set!`, as in `(set! (+ a 1) 5)`, or a
  parameter of a `type` signature.

A field of a call's result, as in `(mut (:x (make)))`, is not a place either. An
argument that is already a `mut` borrow is accepted even when it is not a place,
such as an `if` whose branches return one. `set!` of an `at` form is accepted.

A `mut` argument also fixes the type of the later arguments that share its type
parameter, so `(> (mut x) 3)` reports this error at the `3`, while `(> 3 (mut
x))` reports `L0401` at the `mut`.

A parameter whose `mut` mode the compiler infers from the function's body
reports `L0514` instead, and an `at` read, a `deref` or a `ref` form passed to a
`mut` parameter reports `L0401`.

## Erroneous example

```lisp
(defn starting-scores () (vec 10 20))

(defn main ()
  (push! (starting-scores) 30)
  (println (len (starting-scores))))
```

## Fixes

Bind the vector to a name, and push onto that name:

```lisp
(defn starting-scores () (vec 10 20))

(defn main ()
  (let (scores (starting-scores))
    (push! scores 30)
    (println (len scores))))
```
