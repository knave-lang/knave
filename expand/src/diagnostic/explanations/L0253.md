A library may list libraries of its own in its project file, and a `use` path
that starts with the name of any library of the build, such as `keymap` or
`keymap/extra`, names that library, even one that only another library lists.
This error reports a `use` in the program whose path starts with the name of
such a library, one that the program's project file does not list, when the
program also has a module file or a folder of that name at its source root, such
as `keymap.knv` or `keymap/`. Only a `use` of that path reports it, not the file
or the folder alone, but a test file such as `tests/keymap.knv`, or a task file
such as `tasks/keymap.knv` under `knave check`, reports it at the `use` that the
tests or the tasks make of each file.

Without the local file or folder, the same `use` reports `L0252`. When the
project lists the library itself, the `use` loads the library and reports the
warning `L0251`.

## Erroneous example

```knave
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout)
(use keymap key)

(defn main () (println (shout key)))
;; src/keymap.knv
(export key)

(def key "local")
;; libs/hints/project.knv
(defproject hints (libraries (keymap :path "../keymap")))
;; libs/hints/src/lib.knv
(use keymap key)

(export shout)

(defn shout (text) (str text key "!"))
;; libs/keymap/project.knv
(defproject keymap)
;; libs/keymap/src/lib.knv
(export key)

(def key "k")
```

## Fixes

Move the local module into a folder, and use it by its longer path:

```knave
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout)
(use local/keymap key)

(defn main () (println (shout key)))
;; src/local/keymap.knv
(export key)

(def key "local")
;; libs/hints/project.knv
(defproject hints (libraries (keymap :path "../keymap")))
;; libs/hints/src/lib.knv
(use keymap key)

(export shout)

(defn shout (text) (str text key "!"))
;; libs/keymap/project.knv
(defproject keymap)
;; libs/keymap/src/lib.knv
(export key)

(def key "k")
```
