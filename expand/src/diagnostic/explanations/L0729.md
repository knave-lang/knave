This error reports a name in the `lints` section of `project.knv` that is no lint. Only the `L08xx` lints have a level, so a lint's name is the name that `knave doc <code>` shows for an `L08xx` code, with dashes in place of its spaces, such as `unused-binding` for `L0801`. `L0217`, `L0249`, `L0251` and `L0256` are warnings that always print, and they have no level.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter (lints (unused-bindings allow)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Write the name that `knave doc <code>` shows for the lint's code, with dashes in place of its spaces, such as `unused-binding` for `L0801`:

```knave
;; project.knv
(defproject greeter (lints (unused-binding allow)))
;; src/main.knv
(defn main () (println "hello"))
```
