A parameter with no written type takes its mode from the function's body: a
small `Copy` value is copied, a value that the body only reads is borrowed, one
that it changes is borrowed as `mut`, and one that it keeps is owned. A
`(ref x)` or `(mut x)` written at the call passes as written, with no
adjustment, so it must match that mode exactly: `ref` meets only a borrowed
parameter, and `mut` meets only a parameter borrowed as `mut`.

This argument of a named function writes `ref` or `mut`, and the parameter's
mode is another one. A parameter with a written type takes the argument as its
type says.

## Erroneous example

```lisp
(defn add-one (x) (+ x 1))

(defn main ()
  (local n 4)
  (println (add-one (ref n))))
```

`add-one` copies its number, so a borrow of `n` does not fit.

## Fixes

Pass the value as the parameter takes it:

```lisp
(defn add-one (x) (+ x 1))

(defn main ()
  (local n 4)
  (println (add-one n)))
```

Or write the parameter's type, when it should take a borrow:

```lisp
(defn add-one ((x (ref i64))) (+ x 1))

(defn main ()
  (local n 4)
  (println (add-one (ref n))))
```
