`(macro (form) body ...)` builds a macro, code that the compiler runs while it
expands the program. The compiler registers a macro only from a top-level `def`
that binds the `macro` form itself, so the macro exists before any form that
calls it. Anywhere else the form is this error: bound by `local` in a function
body, returned by a function, or nested inside another value, even a value that
a module-level `def` binds.

## Erroneous example

```lisp
(use code first rest)

(defn main ()
  (local twice
    (macro (form)
      (local action (first (rest form)))
      (template (do (unquote action) (unquote action)))))
  (twice (println "hi")))
```

## Fixes

Move the macro out of `main`:

```lisp
(use code first rest)

(def twice
  (macro (form)
    (local action (first (rest form)))
    (template (do (unquote action) (unquote action)))))

(defn main ()
  (twice (println "hi")))
```

`defmacro` writes the same definition and names the macro's parameters:

```lisp
(defmacro twice (form)
  (template (do (unquote form) (unquote form))))

(defn main ()
  (twice (println "hi")))
```
