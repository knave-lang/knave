`recur` starts the enclosing function again, and its arguments become the
new values of the function's parameters, in order. This error reports a
`recur` whose arguments outnumber the parameters or fall short of them. The
enclosing function is the nearest `fn`, so a `recur` inside a lambda counts
the lambda's parameters, and a `recur` inside a `loop` counts the loop's
bindings.

## Erroneous example

```knave
(defn sum-to (n total)
  (if (= n 0) total (recur (- n 1))))

(defn main () (println (sum-to 4 0)))
```

## Fixes

With a new value for `total`:

```knave
(defn sum-to (n total)
  (if (= n 0)
    total
    (recur (- n 1) (+ total n))))

(defn main () (println (sum-to 4 0)))
```
