This error reports a level in the `lints` section of `project.knv` that is written as a string or a list. A level is one of the words `allow`, `warn` and `deny`, written bare.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter (lints (unused-binding "allow")))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Write the level without quotes:

```knave
;; project.knv
(defproject greeter (lints (unused-binding allow)))
;; src/main.knv
(defn main () (println "hello"))
```
