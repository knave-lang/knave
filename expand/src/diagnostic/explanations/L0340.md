A `(rust "Path")` clause in `defenum`, `deftrait` or `deftype` makes the type
or trait name a Rust one. This error reports a list that starts with `rust` and
then a string, written after a variant, a method, a type, another such clause,
or any other form that follows the name and the docstring.

`deftrait` and `deftype` report this error before they check their other
forms, so `(deftrait number i8 (rust "Copy"))` reports it in place of `L0342`,
and `(deftype meters f64 (rust "f64"))` in place of `L0345`.

## Erroneous example

```knave
(deftrait hex-number
  i8 i16
  (rust "std::fmt::LowerHex"))

(defn main () (println "hex"))
```

## Fixes

Put the clause before the types it lists:

```knave
(deftrait hex-number
  (rust "std::fmt::LowerHex")
  i8 i16)

(defn main () (println "hex"))
```
