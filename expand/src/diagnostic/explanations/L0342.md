A `deftrait` without a `rust` clause defines a trait of the program, and each
form after its name or docstring declares one method, as in
`(deftrait greet (hello (fn ((ref self)) string)))`. This error reports a form
there that is not a list of a symbol, other than a keyword, and at least one
more item, such as a type name like `i8`, a list of one item like `(hello)`,
the empty list, or a list that starts with a keyword or a string. A
`(method name type)` entry, the shape of a Rust trait's method, reports it too.

A list of the right shape whose type is not a function, such as `(hello i64)`,
reports `L0210` instead, and a `rust` clause after other forms reports `L0340`
before this error.

## Erroneous example

```lisp
(deftrait hex-number i8 i16)

(defn main () (println "hex"))
```

## Fixes

To name a Rust trait and the types that implement it, start with its path:

```lisp
(deftrait hex-number (rust "std::fmt::LowerHex") i8 i16)

(defn main () (println "hex"))
```

Or declare methods and implement them:

```lisp
(deftrait hex-number (digits (fn ((ref self)) string)))

(impl hex-number i64
  (digits (self) (str self)))

(defn main () (println (digits 255)))
```
