A call in macro code must pass as many arguments as its callee takes. The
callee may be a function, such as a `fn`, a helper defined with `defn` or a
function bound by `let`, or a built-in of the `code` module that takes a fixed
number of arguments, such as `first` or `nth`. The compiler finds this only
when the call runs, so a macro reports it when one of its calls reaches the
faulty call.

A call of a `defmacro` macro with the wrong number of arguments reports
`L0301` instead.

## Erroneous example

```lisp
(defn pick-first (left right) left)

(defmacro either (left right) (pick-first left))

(defn main ()
  (println (either 1 2)))
```

## Fixes

Pass every argument that the helper takes:

```lisp
(defn pick-first (left right) left)

(defmacro either (left right) (pick-first left right))

(defn main ()
  (println (either 1 2)))
```
