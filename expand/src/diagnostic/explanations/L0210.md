Each kernel form, such as `if`, `match`, `fn` or `local`, has a fixed shape: a
fixed number of parts, each of a given kind. This form has the name of a kernel
form, but its parts do not fit that shape. `knave doc` with the form's name
prints its shape, so `knave doc if` prints `(if test then else)`.

## Erroneous example

```lisp
(defn main ()
  (local n 3)
  (if (> n 2) (println "big")))
```

An `if` always has a test, a branch for a true test and a branch for a false
one, so it always has a value.

## Fixes

Give the `if` its other branch:

```lisp
(defn main ()
  (local n 3)
  (if (> n 2) (println "big") (println "small")))
```

Or use `when`, which runs its body only when the test holds:

```lisp
(defn main ()
  (local n 3)
  (when (> n 2) (println "big")))
```
