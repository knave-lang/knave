The description that `fail` and `warn` take is a list of parts, each a keyword
followed by its value. This error reports a description that the compiler cannot
read, such as one with a part that is not a keyword, a keyword that names no
part, such as `:cod`, or a last part with no value. It also reports a value of
the wrong kind: `:label`, `:note` and `:earlier-label` take a string, `:code`
and `:suggest` take a symbol, and `:once-per` takes the symbol `definition`.

`:earlier` and `:earlier-label` work as a pair, so a description that holds only
one of them reports this error. A `warn` reports a lint, which it names with
`:code`: a description without `:code`, an empty one, and a help string in the
place of the description report this error too.

The compiler reads the description when the `fail` or `warn` call runs, so a
macro reports this error only from a call that reaches it. In place of the
description, `fail` takes only a list: any other value there, such as a string
or a keyword, reports `L0303`. A `:code` symbol that names no diagnostic reports
`L0322`.

## Erroneous example

```knave
(use code warn)

(defmacro placeholder (page)
  (warn "this link is a placeholder" page
    (quote (:code unmatched-link :label placeholder)))
  page)

(defn main () (println (placeholder "home")))
```

## Fixes

Write the label as a string:

```knave
(use code warn)

(defmacro placeholder (page)
  (warn "this link is a placeholder" page
    (quote (:code unmatched-link :label "placeholder")))
  page)

(defn main () (println (placeholder "home")))
```
