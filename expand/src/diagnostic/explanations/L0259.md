A program may bind a kernel type's name in the type namespace: a struct, an
enum, a trait or a Rust type named `float`, a `where` binder such as
`(where (int) ...)`, a type parameter on a struct's, an enum's or a Rust type's
name, or a trait's associated type. The binding hides the kernel type in its
scope, so `float` written there names the program's type, while a type the
compiler prints as `float` is still the kernel type. A mismatch can then read
``expected `float`, found `float` ``, and an `infer` text no longer pastes into
a `type` signature.

This warning reports each such binding under any kernel type's name, such as
`int`, `i64`, `float`, `f64` or `string`, and each `use` that imports one. A
`use` that imports the kernel type itself reports nothing. A library's own
bindings and imports report it only when the library is the program being
checked: a program that uses the library gets the warning at its own `use`.

A binder or a `use` that a macro's template writes hides the kernel type only in
that macro's own code: a type name written at the call still names the kernel
type. The warning points at the binder in the template, with a label on the
call, when the macro whose template writes it belongs to the program, even when
another macro's expansion calls that macro or when the binder sits in a macro
that the template defines. A binder that a library's macro writes reports
nothing in a program that calls it, even in a macro that the library's macro
defines. A binder whose text a call passes into a macro whose definition
another macro's template writes warns at that text, and names no macro, when
the text there spells the binder. A binder that `located` places at other text
of that spelling takes the same form, with its label at that text.

## Erroneous example

```knave
(defstruct float
  :whole i32
  :fraction u32)

(defn main ()
  (println (:whole (->float 3 14))))
```

## Fixes

Give the type a name of its own:

```knave
(defstruct decimal
  :whole i32
  :fraction u32)

(defn main ()
  (println (:whole (->decimal 3 14))))
```
