A `struct`, an `enum` or a `rust-type` that takes type parameters writes its
head as a list, as `(defenum (choice a) ...)` does. This error reports a
definition whose head is a bare name and whose first body form is `(where
(parameter ...) ...)`. It applies to these forms whether the program writes them
or a macro such as `defenum` produces them.

## Erroneous example

```knave
(defenum choice
  (where (a) (one a) (two a a) none))

(defn total (picked)
  (match picked
    ((one x) x)
    ((two x y) (+ x y))
    (none 0)))

(defn main ()
  (println (total (choice/two 2 3))))
```

## Fixes

With the parameters in the head:

```knave
(defenum (choice a)
  (one a)
  (two a a)
  none)

(defn total (picked)
  (match picked
    ((one x) x)
    ((two x y) (+ x y))
    (none 0)))

(defn main ()
  (println (total (choice/two 2 3))))
```
