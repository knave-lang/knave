Every `(` opens a list that a matching `)` closes. The reader reached the end of
the file while this list was still open, so the forms after the `(` have no
end. The cause is usually a missing `)` at the end of a definition, or one
missing inside it that shifts every later `)` by one.

When a string is never closed, the reader reports the string instead, because
the string's missing `"` is what kept the lists open.

## Erroneous example

```lisp
(defn main ()
  (println "hello")
```

## Fixes

Add the `)` where the list ends:

```lisp
(defn main ()
  (println "hello"))
```
