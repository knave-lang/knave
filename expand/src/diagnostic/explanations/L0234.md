Every place that takes a type reports this code when it holds a number, a
string, an empty list `()`, or a list whose head is not a symbol, such as `(5
i64)`. Such places include a `type` signature, a parameter's annotation, a
struct field, a variant's payload, the type of a `rust` form, a trait method's
signature, the type that an `impl` implements, and each type argument, such as
the `"i64"` in `(vec "i64")`.

A list whose head is a symbol that builds no type, such as `(i64)`, reports
`L0212` instead, and a symbol that names no type, such as `println`, reports
`L0201`.

## Erroneous example

```knave
(defstruct point
  :x "i64"
  :y i64)

(defn main ()
  (println (:x (->point :x 1 :y 2))))
```

## Fixes

Write the type's name without quotes:

```knave
(defstruct point
  :x i64
  :y i64)

(defn main ()
  (println (:x (->point :x 1 :y 2))))
```
