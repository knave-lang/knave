Macro code reads the value of each name it uses while it runs. A built-in of
macro code and a definition made by `def` or `defn` have such a value, and this
error reports a name of any other kind.

No program reaches it today: the expander turns those names away before macro
code runs. A macro's name used as a value reports `L0304`, an enum variant
reports `L0316`, a definition that only the program can run reports `L0306`,
and the name of a type is not a value at all, so it reports `L0201`. The error
stays as a guard in the interpreter, in case a new kind of name gets past those
checks.

## Described example

No program reaches this error, so the explanation tests run no example here.

## Fixes

In macro code, read only built-ins of macro code and definitions.
