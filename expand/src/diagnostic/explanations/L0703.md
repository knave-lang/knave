A `defproject` form starts with the project's name, a bare symbol such as
`greeter`. This error reports a `defproject` form with no such name after its
head: nothing at all, a key such as `:version`, or a value of another kind, such
as the string `"greeter"` or a list.

Every command that reads the project reports it, run in the project's folder or
below it, or given a file there: `knave check`, `types`, `lint`, `expand`,
`emit`, `build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```lisp
;; project.knv
(defproject "greeter")
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Write the name as a symbol:

```lisp
;; project.knv
(defproject greeter)
;; src/main.knv
(defn main ()
  (println "hello"))
```
