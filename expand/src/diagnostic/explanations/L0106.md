The reader treats only `(`, `)`, `"`, `;` and whitespace specially, so every
list is written with parentheses. Some characters, such as `[`, `]`, `{` and
`}`, are reserved: they cannot appear in a name, so a program that uses them
for vectors or maps, as other Lisps do, reads clearly as an error.

## Erroneous example

```lisp
(defn main ()
  (local items [1 2 3])
  (println (len items)))
```

## Fixes

Build the vector with `vec`:

```lisp
(defn main ()
  (local items (vec 1 2 3))
  (println (len items)))
```
