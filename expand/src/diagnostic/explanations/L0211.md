A kernel form, such as `if`, `fn`, `match`, `local` or `def`, is a piece of
syntax that the compiler handles itself, and it works only as the head of a
list. Passing it to a function, binding it with `local` or `def`, or naming it
anywhere else that expects a value reports this error. A macro used the same way
reports `L0304` instead.

A local, a parameter or a module's own definition that reuses the name of a
kernel form hides the form, and the name then refers to that binding.

## Erroneous example

```knave
(defn pick (choose ready)
  (choose ready "yes" "no"))

(defn main ()
  (println (pick if true)))
```

## Fixes

Write the form where it is used:

```knave
(defn pick (ready)
  (if ready "yes" "no"))

(defn main ()
  (println (pick true)))
```

Or wrap the form in a function and pass the function:

```knave
(defn pick (choose ready)
  (choose ready))

(defn main ()
  (println (pick (fn (ready) (if ready "yes" "no")) true)))
```
