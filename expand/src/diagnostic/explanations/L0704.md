Each form of a project file reads its own keys. The `defproject` form reads
`:version`, `:entry`, `:lib` and `:edition`. A library entry under `libraries`
reads `:path`, `:git` and `:rev`, and a crate entry under `dependencies` or
`dev-dependencies` reads `:features` and `:path`. This error reports any other
key in one of those forms, such as a misspelled `:entri`, `:branch` in a library
entry, or `:path` in the `defproject` form itself.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```lisp
;; project.knv
(defproject greeter :entri "src/main.knv")
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Spell the key as the form reads it:

```lisp
;; project.knv
(defproject greeter :entry "src/main.knv")
;; src/main.knv
(defn main ()
  (println "hello"))
```
