For a library with `:git` and `:rev`, the command runs `git` to clone the
repository and check out the commit into the user's cache, unless the cache
already holds that commit. This error reports a clone or a checkout that fails,
such as a repository that does not exist or cannot be reached, or a commit that
the repository does not hold. A `:git` that is not a URL, such as
`"hints-repo"`, names a folder relative to the project file.

`knave check`, `types`, `lint`, `expand`, `emit`, `build`, `run`, `test`,
`task`, `eval`, `repl`, `doc --write`, `add` and `remove` report it. `knave fmt`
fetches nothing, so it does not report it.

## Erroneous example

```knave
;; project.knv
(defproject greeter
  (libraries (hints :git "hints-repo" :rev "0123456789abcdef0123456789abcdef01234567")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
```

## Fixes

When the library's files are on disk, name their folder with `:path` instead:

```knave
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
