A Rust trait, declared with `rust-trait` or with a `deftrait` that has a `rust`
clause, lists the types that implement it, and an entry may declare type
parameters with `where`. This error reports an entry whose implementor is one
of the entry's own `where` parameters, with or without bounds, as in
`(where (a) a)` or `(where ((a clone)) a)`. The first type of a `with` entry
counts as the implementor, so `(where (a b) (with a b))` reports it too. The
compiler checks the list even when the program never uses the trait.

A parameter inside another type, as in `(where (a) (vec a))`, is accepted, and
so is a parameter as the second type of `with`, as in
`(where (a) (with string a))`. A lone name that no `where` declares and no
type binds, as `a` in `i64 a`, reports `L0201` instead.

The error stops the trait's list, so a later use of the trait with a type that
the list names, such as `i64` below, reports `L0404` as well.

## Erroneous example

```knave
(deftrait hex (rust "std::fmt::LowerHex")
  i64 u8
  (where ((a hex)) a))

(type keep (where ((a hex)) (fn (a) a)))
(defn keep (value) value)

(defn main ()
  (let (small (the u8 7))
    (println (keep 255))
    (println (keep (ref small)))))
```

## Fixes

Implement the trait for a reference to any type that implements it:

```knave
(deftrait hex (rust "std::fmt::LowerHex")
  i64 u8
  (where ((a hex)) (ref a)))

(type keep (where ((a hex)) (fn (a) a)))
(defn keep (value) value)

(defn main ()
  (let (small (the u8 7))
    (println (keep 255))
    (println (keep (ref small)))))
```

Or list only the types themselves, and pass the value without a borrow:

```knave
(deftrait hex (rust "std::fmt::LowerHex")
  i64 u8)

(type keep (where ((a hex)) (fn (a) a)))
(defn keep (value) value)

(defn main ()
  (let (small (the u8 7))
    (println (keep 255))
    (println (keep small))))
```
