An `impl` names the type that it implements a trait for. This error reports an
`impl` whose implementor is a lone symbol that no type and no value binds: a
symbol meant to stand for every type, as in `(impl labelled a ...)`, or a
misspelled or undefined type name, such as `pont` written for `point`. The
`display` and `show` macros expand to an `impl`, so `(display pont ...)` reports
it too.

A symbol of that kind inside a type with arguments, as in `(vec a)`, is
accepted. A lone symbol that names only a value, such as a function, reports
`L0201` instead.

## Erroneous example

```lisp
(defstruct point :x i64)

(deftrait labelled
  (label (fn ((ref self)) string)))

(impl labelled pont
  (label (p) (str "point")))

(defn main ()
  (println (label (->point :x 1))))
```

## Fixes

Name a type that the program defines:

```lisp
(defstruct point :x i64)

(deftrait labelled
  (label (fn ((ref self)) string)))

(impl labelled point
  (label (p) (str "point")))

(defn main ()
  (println (label (->point :x 1))))
```

To cover every vector, write the vector type with a variable for its
element:

```lisp
(deftrait labelled
  (label (fn ((ref self)) string)))

(impl labelled (vec a)
  (label (items) (str "items")))

(defn main ()
  (println (label (vec 1 2))))
```
