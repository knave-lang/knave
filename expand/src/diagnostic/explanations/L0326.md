Expansion counts the forms that the macro calls of each top-level form, such as
one `defn`, produce. This error reports the call that takes that count past
131,072, such as a recursive macro whose expansion doubles at each step, a macro
that returns one very large form, or several calls that together pass it, and
each later call in the same top-level form. Each top-level form counts on its
own, so calls spread over several of them can expand to more.

It also reports a built-in that macro code calls, such as `value-eq`, when the
built-in turns a list into a form of more than 131,072 forms. A list that holds
the same inner list many times turns into a copy of that inner list at each
place, so it can reach that size from a short loop.

Code that nests too deep reports `L0325`, and macro code that runs too many
steps reports `L0363`. A single value that a built-in builds past its own size
limit reports `L0355`.

## Erroneous example

```lisp
(defmacro both (form)
  (template (both (do (unquote form) (unquote form)))))

(defn main () (both (println "hi")))
```

## Fixes

Expand to the forms with no further call of the macro:

```lisp
(defmacro both (form)
  (template (do (unquote form) (unquote form))))

(defn main () (both (println "hi")))
```
