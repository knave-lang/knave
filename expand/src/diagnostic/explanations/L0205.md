A `use` imports names from a module, and a module offers only the names that its
`export` form lists. Every other name it defines stays private to its file. This
name is not in the module's export list: the module defines it without exporting
it, or does not define it at all, often because of a misspelling. The rule holds
for prelude modules, and for `code` and `kernel`, whose names the compiler
fixes.

## Erroneous example

```knave
(use prelude/macros documnet)

(def limit 10)

(documnet limit "How many items a page shows.")

(defn main ()
  (println limit))
```

## Fixes

Correct the name:

```knave
(use prelude/macros document)

(def limit 10)

(document limit "How many items a page shows.")

(defn main ()
  (println limit))
```
