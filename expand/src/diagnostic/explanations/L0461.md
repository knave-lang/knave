A struct pattern, or the pattern of a variant with named fields, labels one
field twice, such as `(point :x a :x b)` or `(shape/labeled :text a :size b
:text c)`.

A pattern checks its labels in the order written, so the repeated label reports
this error when it comes before a label that names no field or a label with no
pattern after it, and it reports it even when no pattern follows the repeated
label, as `(point :x a :x)` does. A pattern that also holds a part by position
reports `L0462` first. A label used twice in a variant construction, such as
`(shape/labeled :text (str "a") :text (str "b") :size 1.0)`, reports `L0454`
instead.

## Erroneous example

```lisp
(defstruct point :x i64 :y i64)

(defn main ()
  (match (->point :x 1 :y 2)
    ((point :x a :x b) (println a " " b))))
```

## Fixes

Match `:y` with the name `b`:

```lisp
(defstruct point :x i64 :y i64)

(defn main ()
  (match (->point :x 1 :y 2)
    ((point :x a :y b) (println a " " b))))
```

Or match `:x` once, and print its name twice:

```lisp
(defstruct point :x i64 :y i64)

(defn main ()
  (match (->point :x 1 :y 2)
    ((point :x a) (println a " " a))))
```
