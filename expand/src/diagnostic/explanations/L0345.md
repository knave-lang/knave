A `deftype` takes, as the first form after its name or its docstring, a list
headed by `rust` whose second item is a string, such as `(rust
"std::time::Instant")`. This error reports a `deftype` whose first form is
anything else, such as a type of the program, as in `(deftype meters f64)`, a
`rust` list without a string, or no form at all. A `deftype` with nothing after
its name or its docstring reports the error at the name.

A `rust` clause in a later place reports `L0340` instead, and a clause that
holds anything after its string reports `L0341`.

## Erroneous example

```lisp
(deftype counter i64)

(defn main () (println "ok"))
```

## Fixes

Name the Rust type in a `rust` clause:

```lisp
(deftype counter (rust "std::num::Wrapping<i64>"))

(defn main () (println "ok"))
```

Or define a type of the program with `defstruct`:

```lisp
(defstruct counter :count i64)

(defn main () (println (:count (->counter :count 3))))
```
