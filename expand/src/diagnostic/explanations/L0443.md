Each type parameter of an enum takes its type from a variant's payload. This
error reports a type parameter that appears in none of the payload types, at
any depth: in no positional part and no named field. A use inside another type
counts, such as `a` in `(call (fn (a) i64))` or `(at :place (ref a))`. The rule
holds for an enum with a `rust` clause too.

The check reads the parameters in order and reports only the first that fails.
A parameter that the payloads use only inside the enum's own type, such as `a`
in `(link (chain a))`, reports `L0439` instead. A struct's type parameter that
no field uses reports `L0416`.

## Erroneous example

```knave
(defenum (reply a)
  (yes i64)
  no)

(defn main () (println "ready"))
```

## Fixes

Give a payload part the type `a`:

```knave
(defenum (reply a)
  (yes a)
  no)

(defn main () (println "ready"))
```

Or drop `a` from the enum's head:

```knave
(defenum reply
  (yes i64)
  no)

(defn main () (println "ready"))
```
