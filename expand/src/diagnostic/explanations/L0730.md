This error reports a level in the `lints` section of `project.knv` that is none of `allow`, `warn` and `deny`.

The commands that read the project report it before anything else, as they report every problem of `project.knv`.

## Erroneous example

```knave
;; project.knv
(defproject greeter (lints (unused-binding quiet)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Give one of the levels:

```knave
;; project.knv
(defproject greeter (lints (unused-binding allow)))
;; src/main.knv
(defn main () (println "hello"))
```
