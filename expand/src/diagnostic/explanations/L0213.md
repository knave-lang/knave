`deftype` and `rust-type` name a Rust type with a template, Rust text in which
`{0}` stands for the type's first parameter, `{1}` for its second, and so on.
This error means a brace in the template opens no such placeholder: a `{` that
never closes, as in `Box<{0`, a `{}` with nothing inside, a `&` or `owned`
before something other than a number, as in `{&x}` or `{owned x}`, or a `!` with
no name, as in `{!}`. The check covers the template after `rust` and each
template that the definition pairs with one type, such as `(u8
"std::num::NonZeroU8")`.

## Erroneous example

```knave
(deftype (boxed item) (rust "Box<{0"))

(def wrap
  (rust "Box::new({0})"
    (where (a) (fn (a) (boxed a)))))

(def unwrap
  (rust "*{0}"
    (where (a) (fn ((boxed a)) a))))

(defn main ()
  (println (unwrap (wrap 7))))
```

## Fixes

Close the placeholder and the Rust generic:

```knave
(deftype (boxed item) (rust "Box<{0}>"))

(def wrap
  (rust "Box::new({0})"
    (where (a) (fn (a) (boxed a)))))

(def unwrap
  (rust "*{0}"
    (where (a) (fn ((boxed a)) a))))

(defn main ()
  (println (unwrap (wrap 7))))
```
