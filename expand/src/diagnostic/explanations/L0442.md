`quote` returns a form, a value that macro code works on while the compiler
expands the program. This error reports a `quote` form in the program's own
code: in `main`, in any method of an `impl` or default method of a trait, or in
a function or `def` that one of these reaches, at any depth, including inside a
`fn`. A method counts whether or not anything calls it, because the program
always contains it. A `template` of a form that is not a list, such as
`(template hello)`, is a `quote` too.

A function or `def` that holds a `quote` and that none of these reaches, such as
one that only macros use or that nothing uses, reports nothing. A `template` of
a list builds the form with functions of the `code` module, and reports `L0412`
instead.

## Erroneous example

```knave
(defn main () (println (quote hello)))
```

## Fixes

Replace the quoted symbol with a string literal:

```knave
(defn main () (println "hello"))
```

Or let a macro return the `println` call as code:

```knave
(defmacro say-hello ()
  (quote (println "hello")))

(defn main () (say-hello))
```
