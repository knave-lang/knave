An `impl` defines every method that its trait declares, except a method for
which the trait gives a default body. This holds for a trait from `deftrait`
and for a prelude trait such as `display`, so `(impl display label)` with no
methods reports this code. Each method left out reports once.

A misspelled method name leaves the real method out, so it reports this code
for the declared name, and `L0241` for the misspelled one.

## Erroneous example

```knave
(defstruct circle :radius f64)

(deftrait shape
  (area (fn ((ref self)) f64))
  (perimeter (fn ((ref self)) f64)))

(impl shape circle
  (area (c) (* 3.0 (:radius c) (:radius c))))

(defn main ()
  (println (area (->circle :radius 1.0))))
```

## Fixes

Define the method that is left out:

```knave
(defstruct circle :radius f64)

(deftrait shape
  (area (fn ((ref self)) f64))
  (perimeter (fn ((ref self)) f64)))

(impl shape circle
  (area (c) (* 3.0 (:radius c) (:radius c)))
  (perimeter (c) (* 6.0 (:radius c))))

(defn main ()
  (let (unit (->circle :radius 1.0))
    (println (area unit))
    (println (perimeter unit))))
```
