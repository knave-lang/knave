Macro code may nest at most 1,000 function calls, counting the call of the
macro itself. This error reports macro code that nests deeper, such as a
function that calls itself without end, or one that calls itself once for each
step of a long count. Calls through several functions that call each other
count too. A `recur` reuses the call of its function, so a loop that repeats
with `recur` does not nest.

The error appears when a call of the macro runs the code. A macro that no call
runs reports nothing.

## Erroneous example

```lisp
(use code number-add value-eq)

(defn sum-to (n)
  (if (value-eq n 0) 0 (number-add n (sum-to n))))

(defmacro sum-to-ten () (sum-to 10))

(defn main () (println (sum-to-ten)))
```

## Fixes

Count down, so the calls stop at zero:

```lisp
(use code number-add number-sub value-eq)

(defn sum-to (n)
  (if (value-eq n 0) 0 (number-add n (sum-to (number-sub n 1)))))

(defmacro sum-to-ten () (sum-to 10))

(defn main () (println (sum-to-ten)))
```

For a long count, repeat with `recur` and carry the total:

```lisp
(use code number-add number-sub value-eq)

(defn sum-to (n total)
  (if (value-eq n 0)
    total
    (recur (number-sub n 1) (number-add total n))))

(defmacro sum-to-many () (sum-to 5000 0))

(defn main () (println (sum-to-many)))
```
