In code, a list stands for a call or a form, and its first item says which one.
`()` has no first item, so it stands for neither, and it cannot go where a
value goes, such as an argument, a branch of an `if`, or the value of a
`local`. At the top level of a module,
`()` reports `L0207` instead, as any form that is not a definition does.

## Erroneous example

```knave
(defn report (ready)
  (if ready (println "ready") ()))

(defn main () (report true))
```

## Fixes

Write a form that does nothing:

```knave
(defn report (ready)
  (if ready (println "ready") (do)))

(defn main () (report true))
```

Or use `when`, which needs no second branch:

```knave
(defn report (ready)
  (when ready (println "ready")))

(defn main () (report true))
```
