A macro's body runs at compile time, and the value it ends with takes the place
of the call. That value must be a form, such as a number, a string or a symbol,
or a list of forms, such as one that `quote` or `template` builds. This error
reports a call whose macro ends with a boolean, unit or a function, such as the
result of `empty?`. It applies to a call inside a function and to a call at the
top level of a module. A macro whose name is used as a value reports `L0304`
instead.

## Erroneous example

```lisp
(use code empty?)

(defmacro no-arguments? (items ...)
  (empty? items))

(defn main ()
  (println (no-arguments? 1 2)))
```

## Fixes

Return code that holds the answer:

```lisp
(use code empty?)

(defmacro no-arguments? (items ...)
  (if (empty? items)
    (quote true)
    (quote false)))

(defn main ()
  (println (no-arguments? 1 2)))
```
