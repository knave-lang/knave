The reader stores every integer literal in 128 bits before it gives the literal
a type, so an integer literal must lie between -2^127 and 2^127 - 1. This
literal lies outside that range. A literal inside that range that does not fit
its type, such as an `i64`, reports `L0406` instead, and so does a float
literal too large for its type. A float literal never reports this error.

## Erroneous example

```lisp
(defn main ()
  (println 1000000000000000000000000000000000000000))
```

## Fixes

Write the number as a float when an approximate value is enough:

```lisp
(defn main ()
  (println 1e39))
```

Or keep an integer that fits the type you need, such as an `i64`:

```lisp
(defn main ()
  (println 1000000000000000000))
```
