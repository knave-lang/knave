A `derive` form lists the traits that the compiler writes for a struct or an
enum of the program. It accepts a prelude trait whose Rust path ends in a name
that Rust can derive, such as `clone`, `debug` or `ord`, and a trait with a
`structural` clause, such as `show`. This error reports any other trait in the
list, such as `display`, a trait the program defines with methods, or a
`rust-trait` of the program without a `structural` clause, even one whose path
ends in `Clone`.

A name in the list that is a type rather than a trait reports `L0238` instead,
and a name that nothing binds reports `L0201`.

## Erroneous example

```knave
(defstruct point
  :x i64
  :y i64)

(derive point clone display)

(defn main ()
  (println (->point :x 1 :y 2)))
```

## Fixes

Write the text form with the `display` macro, and keep `clone` in the
`derive`:

```knave
(defstruct point
  :x i64
  :y i64)

(derive point clone)

(display point (p)
  "("
  (:x p)
  ", "
  (:y p)
  ")")

(defn main ()
  (println (->point :x 1 :y 2)))
```

Or print the value's printed form with `prn`, through the derived `show`:

```knave
(defstruct point
  :x i64
  :y i64)

(derive point clone show)

(defn main () (prn (->point :x 1 :y 2)))
```
