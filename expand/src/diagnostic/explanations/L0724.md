A library's root module is the file that `(use hints ...)` reads, `src/lib.knv`
in the library's folder unless the library's project file names another with
`:lib`. This error reports a library whose root module file does not exist, such
as a library with only a `src/main.knv`, or a `:lib` that names a missing file.
It reports it whether or not the program uses the library.

The commands that read the project report it as they follow its libraries, and
libraries' own libraries, and stop at the first such problem: `knave check`,
`types`, `lint`, `expand`, `emit`, `build`, `run`, `test`, `task`, `eval`,
`repl`, `doc --write`, `add` and `remove`. `knave fmt` reports it as a warning
and formats the files all the same.

## Erroneous example

```knave
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/hints.knv
(export hint)

(defn hint () "hello")
```

## Fixes

In `hints/project.knv`, give the root module's path:

```knave
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints :lib "src/hints.knv")
;; hints/src/hints.knv
(export hint)

(defn hint () "hello")
```

Or rename the file to `src/lib.knv`:

```knave
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
