In a project, under `knave test`, a `use` in a test file looks for the module in
`tests/` first and then in the source root, and a `use` in a task file does the
same with `tasks/`. This warning reports such a `use` when its whole path names
a module file in both folders, such as `tests/util.knv` and `src/util.knv`, or
`tests/data/util.knv` and `src/data/util.knv`, so no `use` in the files of that
folder reaches the source module. Only a file counts: a folder `src/util/`
beside `tests/util.knv` reports nothing. `knave task`, and `knave check` in a
project, report it for task files too. Each source module reports it once, at
the first `use` written in a file that loads it. A test file that no other file
uses, such as a `tests/util.knv` that holds only tests, reports nothing.

A path that starts with the name of a library reports `L0251`, `L0252` or
`L0253` instead.

## Erroneous example

```lisp
;; knave test
;; project.knv
(defproject app)
;; src/main.knv
(use util twice)

(defn main ()
  (println (twice 2)))
;; src/util.knv
(export twice)

(defn twice (n) (* n 2))
;; tests/util.knv
(export sample)

(def sample 21)
;; tests/doubling.knv
(use util sample)

(deftest doubles (assert (= (* sample 2) 42)))
```

## Fixes

Keep the test helpers in a folder of their own:

```lisp
;; knave test
;; project.knv
(defproject app)
;; src/main.knv
(use util twice)

(defn main ()
  (println (twice 2)))
;; src/util.knv
(export twice)

(defn twice (n) (* n 2))
;; tests/support/samples.knv
(export sample)

(def sample 21)
;; tests/doubling.knv
(use support/samples sample)

(deftest doubles (assert (= (* sample 2) 42)))
```

Or define the sample in the test file, and reach the source module:

```lisp
;; knave test
;; project.knv
(defproject app)
;; src/main.knv
(use util twice)

(defn main ()
  (println (twice 2)))
;; src/util.knv
(export twice)

(defn twice (n) (* n 2))
;; tests/doubling.knv
(use util twice)

(def sample 21)

(deftest doubles (assert (= (twice sample) 42)))
```
