Several positions of a form accept only one kind of name or form, and this form
puts something else in one of them. The cases are:

- a binder that is not a symbol, such as the `5` in `(let (5 1) ...)` or a
  number in a parameter list or in the type parameters of a definition;
- a type given to `new` that is not a struct, such as an enum;
- a lifetime, such as `'a`, where a type goes, or in the parameters of a
  `rust-type`;
- a list type whose head cannot take type arguments, such as `(i64 i64)`, or a
  trait applied like a type;
- a bound that is not a trait, such as `i64` or a number, on a type parameter,
  as a supertrait of a `trait`, or in the `requires` of a `rust-trait`.

## Erroneous example

```knave
(type biggest (where ((t i64)) (fn (t t) t)))

(defn biggest (a b) (if (> a b) a b))

(defn main ()
  (println (biggest 2 3)))
```

## Fixes

Bound the type parameter by a trait:

```knave
(type biggest (where ((t partial-ord)) (fn (t t) t)))

(defn biggest (a b) (if (> a b) a b))

(defn main ()
  (println (biggest 2 3)))
```

Or write the concrete type, without a type parameter:

```knave
(type biggest (fn (i64 i64) i64))

(defn biggest (a b) (if (> a b) a b))

(defn main ()
  (println (biggest 2 3)))
```
