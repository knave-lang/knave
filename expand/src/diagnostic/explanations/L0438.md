An enum whose `rust` clause holds a template, a string with a placeholder such
as `{0}`, names the Rust type that the template writes, such as a tuple. A
construction and a pattern of the enum write the same template, filled with a
variant's positional parts in order.

This error reports such an enum when its variants do not have that shape. It
reports an enum with no variant or with two or more, and a sole variant with no
payload, with named fields such as `(of :first a :second b)`, or with a part
count that differs from the enum's count of type parameters, such as `(of a)`
or `(of a b a)` for `(entry a b)`.

An enum whose `rust` clause holds a path with no placeholder, such as
`"Option"`, takes any variants. A type parameter that no part uses, as in
`(of a a)`, reports `L0443` instead.

## Erroneous example

```lisp
(defenum (entry key value)
  (rust "({0}, {1})")
  (of key))

(defn main ()
  (match (entry/of 1 "one")
    ((of n word) (println n " " word))))
```

## Fixes

Add the missing part, `value`:

```lisp
(defenum (entry key value)
  (rust "({0}, {1})")
  (of key value))

(defn main ()
  (match (entry/of 1 "one")
    ((of n word) (println n " " word))))
```

Or remove the `rust` clause, so that the program defines the enum:

```lisp
(defenum (entry key value) (of key value))

(defn main ()
  (match (entry/of 1 "one")
    ((of n word) (println n " " word))))
```
