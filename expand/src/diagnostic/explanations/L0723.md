This error reports a library whose folder holds no `project.knv`: a `:path`,
read from the folder of the project file that lists it, that names a misspelled
folder, a folder that does not exist, or the project file itself, as in
`hints/project.knv`, or a `:git` commit with no `project.knv` at the root of its
checkout.

The commands that read the project report it as they follow its libraries, and
libraries' own libraries, and stop at the first such problem: `knave check`,
`types`, `lint`, `expand`, `emit`, `build`, `run`, `test`, `task`, `eval`,
`repl`, `doc --write`, `add` and `remove`. `knave fmt` reports it as a warning
and formats the files all the same.

## Erroneous example

```lisp
;; project.knv
(defproject greeter
  (libraries (hints :path "hint")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```

## Fixes

Correct the path:

```lisp
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
