The `code` built-ins that read a list by position report this error when the
position lies past the end of the list: `nth` with an index at or past the
list's length, `first` or `rest` of an empty list, and `take` or `drop` with a
count larger than the list's length. `string-drop` reports it when its count
is larger than the number of characters in the string. `nth` counts from
zero, so the last item of a list of three is at index 2.

A negative index or count reports `L0303` instead.

## Erroneous example

```lisp
(use code nth)

(defmacro third (items) (nth items 3))

(defn main ()
  (println (third (1 2 3))))
```

## Fixes

Count the index from zero:

```lisp
(use code nth)

(defmacro third (items) (nth items 2))

(defn main ()
  (println (third (1 2 3))))
```
