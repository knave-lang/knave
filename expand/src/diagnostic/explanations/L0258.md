A project's `libraries` give each library a name, and a module path that starts
with that name, such as `hints` or `hints/extra`, loads from the library. `knave
test` given a folder or none, `knave task` and `knave check` in a project read
every `.knv` file in `tests/` or `tasks/` as a module, and this error reports
each such file whose module path starts with the name of a library the project
lists, such as `tests/hints.knv` or `tasks/hints/extra.knv`. The file's tests or
tasks would never run, because the library loads in the file's place.

## Erroneous example

```knave
;; knave test
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(defn main () (println "rest"))
;; tests/hints.knv
(deftest adds (assert (= (+ 1 1) 2)))
;; libs/hints/project.knv
(defproject hints)
;; libs/hints/src/lib.knv
(export shout)

(defn shout (text) (str text "!"))
```

## Fixes

Give the file a module path of the program's own, such as `hint-tests`:

```knave
;; knave test
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(defn main () (println "rest"))
;; tests/hint-tests.knv
(deftest adds (assert (= (+ 1 1) 2)))
;; libs/hints/project.knv
(defproject hints)
;; libs/hints/src/lib.knv
(export shout)

(defn shout (text) (str text "!"))
```
