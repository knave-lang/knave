Inside a string, a `\` starts an escape: it and the characters after it stand
for one character. The escapes are `\n`, `\r`, `\t`, `\0`, `\\`, `\"`, `\'` and
`\u{...}`, where the braces hold the hexadecimal code point of a Unicode scalar
value. Any other character after `\` is not an escape, and neither is a `\u`
whose braces are missing or hold no valid code point, such as `\u{d800}`.

## Erroneous example

```knave
(defn main ()
  (println "C:\data"))
```

## Fixes

Write `\\` for a backslash that should stay in the text:

```knave
(defn main () (println "C:\\data"))
```

Or use the escape you meant, such as `\u{...}` for a character by its code
point:

```knave
(defn main () (println "caf\u{e9}"))
```
