A string starts at a `"` and ends at the next `"` that no `\` escapes. The
reader reached the end of the file without finding that closing `"`, so the
rest of the file reads as part of the string. A string may span several lines,
so the missing `"` can be far above the end of the file.

Because the string swallowed every later `)`, the reader reports no unclosed
list on top of this error.

## Erroneous example

```lisp
(defn main ()
  (println "hello))
```

## Fixes

Add the `"` where the string ends:

```lisp
(defn main ()
  (println "hello"))
```

Or, when the string should hold a `"`, escape it as `\"`:

```lisp
(defn main ()
  (println "she said \"hello\""))
```
