This error reports a form inside `defproject`, after the project's name, that
does not follow a key and is not a list that starts with a symbol, such as a
string or a second symbol on its own, an empty list, or a list that starts with
a string. Inside a library or crate entry, it reports every form after the name
and the optional version that is neither a key nor a key's value, a list
included, such as a second version string in `(serde "1.0" "1.1")` or a bare
name in `(hints :path "hints" extra)`.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter "src/main.knv")
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Name the setting with its key:

```knave
;; project.knv
(defproject greeter :entry "src/main.knv")
;; src/main.knv
(defn main ()
  (println "hello"))
```
