`update` applies a function to one part of a value, and its key decides how many
arguments follow the key. With a keyword key, `update` changes a field of a
struct, as in `(update item :count neg)`, where the function is the only form
after the key. With any other key, such as a map key or a vector index, `update`
changes a collection, as in `(update counts "a" neg 0)`, where the `0` serves
when the key is missing.

This error reports an `update` whose count of forms after its key differs from
these shapes, such as a field update with nothing or with two arguments, or a
collection update with one argument, nothing, or three. An `update` with no key
at all reports `L0301` instead.

## Erroneous example

```knave
(defstruct item :count i64)

(defn main ()
  (println (:count (update (->item :count 1) :count neg 0))))
```

## Fixes

Pass only `neg` after `:count`:

```knave
(defstruct item :count i64)

(defn main ()
  (println (:count (update (->item :count 1) :count neg))))
```
