`(box shape)` in a type position, where `shape` is a trait, holds a value of any
implementor of the trait, and a call of a method finds the implementor's code at
run time. For a trait that `deftrait` defines without a `rust` clause, the
compiler accepts this only when the trait declares no associated type and each
method, a method with a default body included, has `(ref self)` or `(mut self)`
as its first parameter and a result other than `self`. This error reports a
`(box ...)` of a trait that breaks one of those rules, such as a method whose
first parameter is `self` or `i64`, wherever the type appears, such as a
signature, a field of a struct, an enum payload, a `let` binding or a `the`
form.

A trait that `rust-trait` binds, or that `deftrait` binds with a `rust` clause,
such as `display`, reports nothing here, and a trait name written outside `(box
...)` reports `L0449`.

## Erroneous example

```knave
(deftrait shape (area (fn (self) f64)))

(defstruct circle
  :radius f64)

(impl shape circle
  (area (c) (:radius c)))

(defn total ((shapes (vec (box shape))))
  (len shapes))

(defn main ()
  (println (total (vec (box (->circle :radius 2.0))))))
```

## Fixes

Declare the method's first parameter as `(ref self)`:

```knave
(deftrait shape
  (area (fn ((ref self)) f64)))

(defstruct circle
  :radius f64)

(impl shape circle
  (area (c) (:radius c)))

(defn total ((shapes (vec (box shape))))
  (len shapes))

(defn main ()
  (println (total (vec (box (->circle :radius 2.0))))))
```

Or hold the struct itself, when every element has one type:

```knave
(deftrait shape (area (fn (self) f64)))

(defstruct circle
  :radius f64)

(impl shape circle
  (area (c) (:radius c)))

(defn total ((shapes (vec circle)))
  (len shapes))

(defn main ()
  (println (total (vec (->circle :radius 2.0)))))
```
