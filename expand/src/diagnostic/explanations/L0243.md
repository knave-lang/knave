A list whose head is a field keyword, such as `(:x p)`, reads the field `x` of
the struct `p`. A list with nothing after the keyword, as `(:x)`, or with a
second argument, as `(:x p q)`, is this error. A macro that adds an argument
counts too: `(-> p (:x 1))` becomes `(:x p 1)`.

A keyword alone, outside the head of a list, is a function that reads the field,
so `:x` as a value is not this error. A keyword with no value in a call that
labels its arguments, such as `(->point :x)`, is `L0338`.

## Erroneous example

```lisp
(defstruct point :x i64 :y i64)

(defn main ()
  (let (p (->point :x 1 :y 2)
        q (->point :x 3 :y 4))
    (println (:x p q))))
```

## Fixes

Read the field of each struct in its own list:

```lisp
(defstruct point :x i64 :y i64)

(defn main ()
  (let (p (->point :x 1 :y 2)
        q (->point :x 3 :y 4))
    (println (+ (:x p) (:x q)))))
```
