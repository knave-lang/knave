# Language reference

This reference describes the Knave language: how to write a program and what each form of it does. The prelude pages describe each function and macro of the prelude, and `knave doc <code>` explains each diagnostic code.

Each example is a whole program that `knave run` builds and runs. The `text` block after an example is what the example prints.

## Pages

- [Bindings](reference/bindings.md): bind names with `let`, change them with `set!`, and define module-level names with `def`.
