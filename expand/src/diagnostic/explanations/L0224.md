In a `rust` template, `{&0}` passes a borrow of the first argument. The
placeholders of a type template stand for types, which the compiler writes in as
they are. A `&` inside the braces is this error in the template of a `deftype`
or a `rust-type`, in the template of each of its clauses, and in the type
template of the `(rust "...")` clause of a `defenum` or an `enum`.

## Erroneous example

```knave
(deftype (shared item) (rust "std::rc::Rc<{&0}>"))

(def share
  (rust "std::rc::Rc::new({0})"
    (where (a) (fn (a) (shared a)))))

(def peek
  (rust "*{0}" (where (a) (fn ((shared a)) a))))

(defn main ()
  (let (count (share 3))
    (println (peek count))))
```

## Fixes

```knave
(deftype (shared item) (rust "std::rc::Rc<{0}>"))

(def share
  (rust "std::rc::Rc::new({0})"
    (where (a) (fn (a) (shared a)))))

(def peek
  (rust "*{0}" (where (a) (fn ((shared a)) a))))

(defn main ()
  (let (count (share 3))
    (println (peek count))))
```
