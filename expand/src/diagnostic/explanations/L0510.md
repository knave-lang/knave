A borrow refers to a value that something else owns, and it must not outlive
that owner. This function returns a borrow of a value that the function owns and
drops when it returns: a `local` or another binding of the body, a parameter
that owns its value, a closure's parameter that owns its value, or a temporary
that the body builds, such as the result of a call. The borrow may be the result
itself, a branch of an `if` or a `match`, or the last form of a `do`, that ends
the body, or a part of the result: a struct field declared with a borrowed type
such as `str`, or the payload of any variant, such as `(some (ref text))`.

knave checks the result of every function, and of every closure whose result can
hold a borrow. A parameter with no written type takes its mode from its uses, so
a function may return a borrow of a parameter it only reads. A constant
expression such as `(ref (+ 1 2))` lives for the whole program.

## Erroneous example

```knave
(defn greeting ()
  (local text (str "Leaf"))
  (ref text))

(defn main ()
  (println (greeting)))
```

## Fixes

Return the owned value:

```knave
(defn greeting ()
  (local text (str "Leaf"))
  text)

(defn main ()
  (println (greeting)))
```

Or borrow from a value that the caller owns, passed as a parameter:

```knave
(defn greeting (names)
  (at names 0))

(defn main ()
  (local names (vec (str "Leaf") (str "Ariya")))
  (println (greeting names))
  (println (len names)))
```
