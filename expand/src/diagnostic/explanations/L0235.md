Each case of an `enum` is a symbol, or a list whose head is a symbol
followed by the payload's types. The symbol becomes the case's name. In this
`enum`, a case's list starts with something else: a number, a string or a
list, as in `(5 float)` or `((circle) float)`.

`defenum` checks its cases before the `enum` it writes, so the same mistake
in a `defenum` reports `L0346` instead.

## Erroneous example

```knave
(enum shape ("circle" float) point)

(defn main () (println "shapes"))
```

## Fixes

Start the case with a symbol:

```knave
(enum shape (circle float) point)

(defn main ()
  (match (shape/circle 2.0)
    ((circle radius) (println radius))
    (point (println "point"))))
```
