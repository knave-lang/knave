This error reports a file, given to `knave emit`, `knave build` or `knave run`,
that has no top-level definition named `main` whose value is a `fn` form after
expansion. `defn` writes such a definition, and so does a macro that expands to
`(defn main ...)`.

So a file reports this error when no top-level definition carries the name
`main`, such as an empty file or a function spelled `Main`. It also reports it
when the definition named `main` holds some other value, such as a number, the
name of another function as in `(def main start)`, a `fn` wrapped in `let` or
`if`, or a `rust` form. A macro named `main`, a `main` bound by `let` inside a
function, and a `main` that the file imports from another module with `use`
report it too.

`knave check` reports nothing for such a file. A `fn` named `main` that takes
parameters does not report this error.

## Erroneous example

```lisp
(defn start () (println "ready"))

(def main start)
```

## Fixes

Write `main` as a function that calls the other one:

```lisp
(defn start () (println "ready"))

(defn main () (start))
```

Or give the function itself the name `main`:

```lisp
(defn main () (println "ready"))
```
