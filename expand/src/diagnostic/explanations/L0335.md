`let`, `loop`, `let-try` and `let-match` bind the names of their binding list
for the forms that follow the list. This error reports one of these forms that
ends right after its binding list, such as `(let (total 5))`. An empty binding
list, as in `(let ())`, reports it too.

The compiler checks the binding list first, so a list with a name and no value
reports `L0334`, and a binding list that is missing or malformed reports
`L0336`, even when nothing follows the list either.

## Erroneous example

```lisp
(defn main ()
  (let (total 5))
  (println "done"))
```

## Fixes

Put the `println` of `total` inside the `let`:

```lisp
(defn main ()
  (let (total 5)
    (println total))
  (println "done"))
```

Or bind the name at the top level of the module:

```lisp
(def total 5)

(defn main ()
  (println total)
  (println "done"))
```
