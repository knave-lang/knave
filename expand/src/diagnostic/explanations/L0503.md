A parameter that owns its value, either by its written type or because the
function keeps it, such as by storing it in a struct or returning it, needs the
caller to give the value away. This argument is a value that the caller can
only borrow, so it cannot be given away. Such a value is:

- a top-level `def` whose value is not `Copy`, not a function and not a `rust`
  form, since the program holds one value that every use borrows;
- a field read, such as `(:name ana)`, of a field that is not `Copy`, even from
  a local that the caller owns;
- an element that `at` reads, when the element is not `Copy`;
- a local bound to a `(ref ...)`, or a borrowed iterator pipeline;
- a field that a macro such as `update` passes on as a borrow.

The same holds for an argument of `recur` when the loop's parameter owns its
value. A `def` also cannot move anywhere else that takes ownership, such as a
constructor's field value, another `def`'s value or a function's result. A
generic parameter takes a borrowed argument as it is, so the other cases report
only at a parameter of a concrete type. A `def` reports at any parameter.

## Erroneous example

```knave
(def names (vec (str "ana") (str "bo")))

(defn keep (items) items)

(defn main () (println (len (keep names))))
```

## Fixes

Pass a `clone`, which the function can own:

```knave
(def names (vec (str "ana") (str "bo")))

(defn keep (items) items)

(defn main () (println (len (keep (clone names)))))
```

Or call a function that only reads the value, so it takes a borrow:

```knave
(def names (vec (str "ana") (str "bo")))

(defn size (items) (len items))

(defn main () (println (size names)))
```
