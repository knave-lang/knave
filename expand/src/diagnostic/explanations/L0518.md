A borrow lasts from where it is made to the last use of the value that
holds it. While it lasts, the borrowed value cannot change, and it cannot be
lent as `mut`. A `mut` borrow also stops every other borrow of its value
while it lasts. This program changes a value, or borrows it, while an earlier
borrow of it is still in use.

A borrow of a field or an element borrows the whole value it comes from, so
`(at v 0)` borrows `v`. Two different fields of one value do not overlap.

## Erroneous example

```knave
(defn main ()
  (local v (vec 1 2))
  (local first (at v 0))
  (push! v 3)
  (println first))
```

## Fixes

Finish using the borrow before the change:

```knave
(defn main ()
  (local v (vec 1 2))
  (local first (at v 0))
  (println first)
  (push! v 3))
```

Or copy what you need out of the value first, so nothing borrows it:

```knave
(defn main ()
  (local v (vec 1 2))
  (local first (deref (at v 0)))
  (push! v 3)
  (println first))
```
