A function that returns a closure keeps a borrow of each parameter that the
closure reads, directly or through a local built from it. The caller's argument
must live as long as the result. This error reports a call that passes a
temporary, such as `(str "ana")` or `(vec 1 2 3)`, for such a parameter, when
the result outlives the statement: bound with `let` or by a `loop`, or returned.
The temporary is dropped at the end of the statement, or when the function
returns for a returned result, while the closure still borrows it. An argument
that already is a reference, such as `(as-str s)`, borrows no temporary.

A result used inside the same statement, as `((greeter (str "ana")))`, keeps
the temporary alive long enough, so the call is allowed.

## Erroneous example

```knave
(defn greeter (name) (fn () (println (str "hi " name))))

(defn main ()
  (let (greet (greeter (str "ana")))
    (greet)))
```

## Fixes

Bind the value first, so it lives as long as the closure:

```knave
(defn greeter (name) (fn () (println (str "hi " name))))

(defn main ()
  (let (name (str "ana")
        greet (greeter name))
    (greet)))
```

A function that returns the result cannot bind the value itself, because no
local of the function outlives what it returns. Take the value as a parameter,
so the caller keeps it alive:

```knave
(defn greeter (name) (fn () (println (str "hi " name))))

(defn named-greeter (name) (greeter name))

(defn main ()
  (let (name (str "ana")
        greet (named-greeter name))
    (greet)))
```

Or call the result in the same statement:

```knave
(defn greeter (name) (fn () (println (str "hi " name))))

(defn main () ((greeter (str "ana"))))
```
