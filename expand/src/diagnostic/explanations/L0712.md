A library entry under `libraries` names where the library's files are, with
`:path` for a folder or `:git` and `:rev` for a commit of a repository. This
error reports a library entry with neither `:path` nor `:git`, such as
`(hints)`, an entry with `:rev` alone, or one whose only `:path` or `:git` has
no value.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```lisp
;; project.knv
(defproject greeter
  (libraries (hints)))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```

## Fixes

Give the folder that holds the library's project file:

```lisp
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
