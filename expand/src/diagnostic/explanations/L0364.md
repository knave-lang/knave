Code that the compiler runs at compile time reaches the program through groups
of operations that the place where it runs offers. This error reports a call of
a built-in, or a read of a global, that needs a group the place does not offer.
A macro is offered every group. A lint rule can read globals, ask whether two
names name the same binding, ask where a form was written and which macro wrote
it, and report warnings, and nothing more. A rule that called any other
built-in of macro code, such as `current-module`, `module-notes`,
`add-module-note`, `definition-symbol`, `declare-definition` or `expand-call`,
would report it.

## Described example

No program reaches this error, so the explanation tests run no example here.
Only `knave lint` runs code outside a macro, and that code is the rules of
`prelude/lint`, which a project cannot replace and which call none of those
built-ins.

## Fixes

Call a built-in that only a macro may call from a macro alone.
