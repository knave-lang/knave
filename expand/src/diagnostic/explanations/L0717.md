A project's `:edition` names the version of the language that its files are
written in, as a whole number. This error reports any number other than 2026,
such as `2024`. A project without `:edition` takes edition 2026.

Every command that reads the project reports it, run in the project's folder or
below it, or given a file there: `knave check`, `types`, `lint`, `expand`,
`emit`, `build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```lisp
;; project.knv
(defproject greeter :edition 2024)
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Remove the key:

```lisp
;; project.knv
(defproject greeter)
;; src/main.knv
(defn main ()
  (println "hello"))
```

Or write 2026:

```lisp
;; project.knv
(defproject greeter :edition 2026)
;; src/main.knv
(defn main ()
  (println "hello"))
```
