A field bound, `(has :field type)`, holds for every struct that declares the
field. This error reports a bound whose field only one struct declares, because
that struct is then the only type the bound could hold for, and the signature
reads more plainly with the struct itself.

## Erroneous example

```knave
(defstruct cat :age int)

(type age-of (where ((a (has :age int))) (fn ((ref a)) int)))
(defn age-of (x) (:age x))

(defn main () (println (age-of (->cat 1))))
```

## Fixes

Name the struct in the signature:

```knave
(defstruct cat :age int)

(type age-of (fn ((ref cat)) int))
(defn age-of (x) (:age x))

(defn main () (println (age-of (->cat 1))))
```
