Every `)` closes the list that the nearest open `(` started. This `)` stands at
the top level of the file, where no list is open, so it closes nothing. The
cause is usually one `)` too many at the end of a definition, or a `(` missing
earlier in the same definition.

## Erroneous example

```knave
(defn main ()
  (println "hello")))
```

## Fixes

Remove the extra `)`:

```knave
(defn main () (println "hello"))
```

Or, when a `(` is missing, add it where the list starts:

```knave
(defn main () (println (+ 1 2)))
```
