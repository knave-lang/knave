The compiled program's `main` must give Rust an exit status, which knave
derives from `unit`, as a success, or from a `result`, whose `err` prints and
exits 1. This error reports a `main` whose inferred result type is anything
else, such as a number, a `string`, an `option` or a closure. The type is that
of the last form of the body, and when that form is a `let`, an `if` or a `do`,
of the form that ends it. A `type` signature for `main` that names another
result type, or a `main` written as `(def main (fn () ...))`, reports it too.

The compiler checks the result of `main` only after the rest of the program has
passed its type and ownership checks, so an error elsewhere is reported in its
place. A `result` whose error type stays open, as `(ok 5)` at the end of `main`
does, reports `L0407` instead.

## Erroneous example

```knave
(defn total (first second) (+ first second))

(defn main () (total 2019 2021))
```

## Fixes

Print the total at the end of `main`:

```knave
(defn total (first second) (+ first second))

(defn main ()
  (println (total 2019 2021)))
```

Or let `main` fail with an `err`, which exits 1:

```knave
(defn total (first second) (+ first second))

(defn main ()
  (let (sum (total 2019 2021))
    (if (> sum 0)
      (ok (println sum))
      (err "no years"))))
```
