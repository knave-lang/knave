knave reads a project's name and settings from a `defproject` form, the first
form of its `project.knv`. This error reports a project file whose first form is
something else, such as `(project greeter)`, a bare name, or a section such as
`(libraries)` written on its own, and a project file that holds no form, such as
an empty file or one of comments only. The compiler checks nothing more in that
file, except that a second form also reports `L0702`.

Every command that reads the project reports it, run in the project's folder or
below it, or given a file there: `knave check`, `types`, `lint`, `expand`,
`emit`, `build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(project greeter)
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Write `defproject` as the head of the first form:

```knave
;; project.knv
(defproject greeter)
;; src/main.knv
(defn main ()
  (println "hello"))
```
