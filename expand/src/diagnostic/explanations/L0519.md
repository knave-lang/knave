A borrow lasts from where it is made to the last use of the value that
holds it. While it lasts, the borrowed value cannot move, because the borrow
would point at a value that is gone. This program moves a value while an
earlier borrow of it is still in use.

A borrow of a field or an element borrows the whole value it comes from, so
moving the value moves every part a borrow points into.

## Erroneous example

```knave
(defn main ()
  (local names
    (vec (str "ada") (str "grace")))
  (local first (at names 0))
  (local moved names)
  (println first)
  (println (len moved)))
```

## Fixes

Finish using the borrow before the move:

```knave
(defn main ()
  (local names
    (vec (str "ada") (str "grace")))
  (local first (at names 0))
  (println first)
  (local moved names)
  (println (len moved)))
```

Or move a copy of the value, and keep the original for the borrow:

```knave
(defn main ()
  (local names
    (vec (str "ada") (str "grace")))
  (local first (at names 0))
  (local moved (clone names))
  (println first)
  (println (len moved)))
```
