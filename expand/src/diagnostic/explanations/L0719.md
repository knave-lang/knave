This error reports `knave repl` or `knave eval` in a project that lists a crate
under `dependencies`, or that lists a library whose project file does. Crates
under `dev-dependencies` do not report it. `knave eval` reports it when the
module it evaluates lies in such a project, and `knave repl` when it starts in
one.

## Erroneous example

```lisp
;; knave eval src/main.knv (greeting)
;; project.knv
(defproject greeter
  (dependencies (serde "1.0")))
;; src/main.knv
(defn greeting () "hello")

(defn main ()
  (println (greeting)))
```

## Fixes

When only the tests use the crate, list it under `dev-dependencies`:

```lisp
;; knave eval src/main.knv (greeting)
;; project.knv
(defproject greeter
  (dev-dependencies (serde "1.0")))
;; src/main.knv
(defn greeting () "hello")

(defn main ()
  (println (greeting)))
```
