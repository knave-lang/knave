`(type name type)` writes the type of a `def` or a `defn` that the same file
defines. Here `name` resolves to something else: a function from another module,
such as the prelude's `println`, a variant constructor such as `shape/circle`, a
kernel form such as `if`, or a macro. A macro of this module passes only when
its name, used as a value, expands to a function that the macro defined in this
module.

A name that resolves to nothing reports `L0201` instead.

## Erroneous example

```lisp
(type println (fn (i64) unit))

(defn main ()
  (println 1))
```

## Fixes

Define a function of your own and give the signature its name:

```lisp
(type show-count (fn (i64) unit))
(defn show-count (n) (println n))

(defn main ()
  (show-count 1))
```
