A function whose name ends in `!` may change its parameters with `set!`, and the
caller sees each change in the place it passed. A number, a `bool` and every
other `Copy` value has no place unless it is stored in one, such as a local.
This argument is a computed value, so the change would apply to a temporary
value that nothing reads.

## Erroneous example

```lisp
(defn bump! (n) (set! n (+ n 1)))

(defn main ()
  (bump! (+ 1 2)))
```

## Fixes

Store the value in a local, pass the local, and read it afterwards:

```lisp
(defn bump! (n) (set! n (+ n 1)))

(defn main ()
  (local count (+ 1 2))
  (bump! count)
  (println count))
```

Or return the new value instead of changing the argument:

```lisp
(defn bumped (n) (+ n 1))

(defn main ()
  (println (bumped (+ 1 2))))
```
