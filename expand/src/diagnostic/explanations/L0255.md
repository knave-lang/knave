The prelude keeps the code that its forms expand to in modules under
`prelude/internal/`. A `use` of such a path from outside the prelude reports
this error, from a program's file or from a library's, whether the path names
an embedded module such as `prelude/internal/macros` or the compiler-provided
`prelude/internal/code`. A path under `prelude/internal/` that names no module
reports `L0204` instead.

## Erroneous example

```knave
(use prelude/internal/macros whole-pairs?)

(defn main ()
  (println "ready"))
```

## Fixes

Import the public module that offers the form you need, such as
`prelude/macros`:

```knave
(use prelude/macros document)

(defn greet (name) (println "hello " name))

(document (greet name) "Says hello to a name.")

(defn main ()
  (greet "ada"))
```
