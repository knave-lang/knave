Each type parameter of a struct must appear in the type of at least one of its
fields, as `a` does in `:items (vec a)` or in a function type such as
`:make (fn () a)`. This error reports the first type parameter of a
`defstruct` or `struct` that the field types leave out. A lifetime parameter is
exempt.

An enum's type parameter that no payload names reports `L0443`, and a
`rust-type` parameter that the template leaves out reports `L0226`.

## Erroneous example

```knave
(defstruct (tagged a b)
  :value a)

(defn main ()
  (println (:value (->tagged 1))))
```

## Fixes

Declare only the parameters that the fields need:

```knave
(defstruct (tagged a)
  :value a)

(defn main ()
  (println (:value (->tagged 1))))
```

Or add the field that holds a `b`:

```knave
(defstruct (tagged a b)
  :value a
  :label b)

(defn main ()
  (println (:label (->tagged 1 "one"))))
```
