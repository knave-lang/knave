A project's `:knave` names the Knave version that the project uses, and this
warning reports a `knave` newer than that version. CI installs the version the
key names, so its results can differ from what this compiler reports.

Every command that finds the project reports it, except `knave upgrade`, which
records the running version and so clears the warning. A library's `:knave` is
never checked. A project without `:knave` is never checked either.

## Described example

The warning depends on the running compiler's version, so the explanation tests
run none here. A project that records Knave 0.1.0, checked by any later `knave`,
reports it:

```text
(defproject greeter :knave "0.1.0")
```

## Fixes

Run `knave upgrade`. It sets `:knave` to the running compiler's version, so a
`knave` 0.19.0 leaves `(defproject greeter :knave "0.19.0")`, which that
compiler no longer warns on. It also rewrites each file that an earlier Knave
wrote and that nobody changed since.
