This error reports a setting that a project file gives twice in one place: a key
twice in one form, such as `:version` twice in `defproject` or `:path` twice in
one library entry, a section twice in `defproject`, or one name twice in one
section, such as two `hints` entries under `libraries`. It does not report one
crate under both `dependencies` and `dev-dependencies`.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter :version "1.0.0" :version "1.1.0")
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Keep the version you mean:

```knave
;; project.knv
(defproject greeter :version "1.1.0")
;; src/main.knv
(defn main ()
  (println "hello"))
```
