`defn` and `defmacro` take the parameter list right after the name. This error
reports a string in that place, whether more forms follow it or not, inside a
function body as well as at the top level of a module.

A body that holds only a string returns that string.

## Erroneous example

```lisp
(defn twice "Doubles a number." (x) (* 2 x))

(defn main () (println (twice 4)))
```

## Fixes

Put the parameter list right after the name:

```lisp
(defn twice (x) "Doubles a number." (* 2 x))

(defn main () (println (twice 4)))
```
