`derive` implements each trait named after its target, such as `clone`, for
that target. Here one of those names resolves to a type, such as `string` or
the target struct itself.

A name that resolves to nothing, such as a misspelled trait, reports `L0201`
instead.

## Erroneous example

```lisp
(defstruct ticket :id u32)

(derive ticket string)

(defn main ()
  (println (:id (->ticket :id 1))))
```

## Fixes

Name the trait:

```lisp
(defstruct ticket :id u32)

(derive ticket clone)

(defn main ()
  (let (first (->ticket :id 1)
        second (clone first))
    (println (:id second))))
```
