A parameter with no written type that the function keeps, such as by storing it
in a struct or returning it, owns its value, so the caller must give the value
away. This argument is a value that the caller can only borrow, so it cannot be
given away. Such a value is:

- a top-level `def` whose value is not `Copy` and not a function, since the
  program holds one value that every use borrows;
- a field read, such as `(:name ana)`, of a field that is not `Copy`, even from
  a local that the caller owns;
- an element that `at` reads, when the element is not `Copy`;
- a local bound to a `(ref ...)`, or a borrowed iterator pipeline;
- a field that a macro such as `update` passes on as a borrow.

A `def` also cannot become a constructor's field value, another `def`'s value,
or a function's result. A parameter of a generic type takes a borrow as it is,
so only a parameter of a concrete type reports this.

## Erroneous example

```lisp
(def names (vec (str "ana") (str "bo")))

(defn keep (items) items)

(defn main () (println (len (keep names))))
```

## Fixes

Pass a `clone`, which the function can own:

```lisp
(def names (vec (str "ana") (str "bo")))

(defn keep (items) items)

(defn main () (println (len (keep (clone names)))))
```

Or call a function that only reads the value, so it takes a borrow:

```lisp
(def names (vec (str "ana") (str "bo")))

(defn size (items) (len items))

(defn main () (println (size names)))
```
