A `match` tests a value of the program against patterns, and macro code runs
while the compiler expands the program, so its values are forms. This error
reports a `match` in macro code, whether the macro body writes it or a macro
that the body calls expands to it, such as `let-match`.

The compiler checks the macro body when it defines the macro, along with each
function or `def` that the body calls or reads, so a macro reports this error
even when no call runs its `match`.

## Erroneous example

```knave
(defmacro pick (form)
  (match form
    (1 (quote "one"))
    (_ (quote "other"))))

(defn main () (println (pick 1)))
```

## Fixes

Test the form with `if` and a built-in of `code`, such as `value-eq`:

```knave
(use code value-eq)

(defmacro pick (form)
  (if (value-eq form 1) (quote "one") (quote "other")))

(defn main () (println (pick 1)))
```

Or let the program run the `match`, by writing it into the macro's expansion:

```knave
(defmacro pick (form)
  (template
    (match (unquote form)
      (1 "one")
      (_ "other"))))

(defn main () (println (pick 1)))
```
