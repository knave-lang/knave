Code that the compiler runs at compile time reaches the program through groups
of operations that the place where it runs offers. This error reports a call of
a built-in, or a read of a global, that needs a group the place does not offer.
A macro is offered every group. A lint rule cannot list or read the program's
modules, read or add module notes, or expand a macro call, so a rule that
called `current-module`, `module-notes`, `add-module-note` or `expand-call`
would report it.

No program reaches it today. Only `knave lint` runs code outside a macro, and
that code is the rules of `prelude/lint`, which a project cannot replace and
which call none of those built-ins.

## Described example

No program reaches this error, so the explanation tests run no example here.

## Fixes

Call a built-in that reads or changes the program's modules only from a macro.
