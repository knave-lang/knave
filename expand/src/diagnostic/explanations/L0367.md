A project's `exported-tasks` section names the tasks that every project listing
it under `libraries` can run with `knave task`. Each name must be the name that
a `deftask` under the project's `tasks/` gives its task. This error reports a
name of the section that no task of the project takes, such as a misspelled
name or a task that moved or was renamed, at its place in the project file.

The error comes from the step that collects the names of every task, so `knave
task`, `knave task <name>` for any name, and `knave check` and `knave lint` with
no file report it. A project with the section and no `tasks/` folder reports
each name.

## Erroneous example

```knave
;; knave task
;; project.knv
(defproject linter (exported-tasks lnt))
;; src/main.knv
(defn main () (println "lint with a task"))
;; tasks/lint.knv
(deftask lint () (println "no problems found"))
```

## Fixes

Spell the name as the `deftask` does:

```knave
;; knave task lint
;; project.knv
(defproject linter (exported-tasks lint))
;; src/main.knv
(defn main () (println "lint with a task"))
;; tasks/lint.knv
(deftask lint () (println "no problems found"))
```

Or define the task under `tasks/`:

```knave
;; knave task lnt
;; project.knv
(defproject linter (exported-tasks lnt))
;; src/main.knv
(defn main () (println "lint with a task"))
;; tasks/lint.knv
(deftask lint () (println "no problems found"))

(deftask lnt () (println "no problems found"))
```
