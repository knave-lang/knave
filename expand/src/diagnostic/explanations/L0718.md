This error reports a project name, the symbol after `defproject`, that holds a
character other than a lowercase letter, a digit or a dash, that starts with
something other than a lowercase letter, or that has a dash at its end or two in
a row. Such names are `Greeter`, `my_greeter`, `greeter-` and `my--greeter`.

Every command that reads the project reports it, run in the project's folder or
below it, or given a file there: `knave check`, `types`, `lint`, `expand`,
`emit`, `build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

`knave new` reports it for the name it is given, such as `knave new My_Tool`,
and creates no files. It also reports a name there that starts with a digit,
such as `2tool`. In a project file, such a name reads as a number and reports
`L0105`.

## Erroneous example

```lisp
;; project.knv
(defproject my_greeter)
;; src/main.knv
(defn main ()
  (println "hello"))
```

## Fixes

Join the words with a dash:

```lisp
;; project.knv
(defproject my-greeter)
;; src/main.knv
(defn main ()
  (println "hello"))
```
