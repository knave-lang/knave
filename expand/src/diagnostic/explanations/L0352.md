`prn` prints the printed forms of its arguments, separated by a space, so
`(prn 1 "a")` prints `1 "a"`. This error reports a call of `prn` with no
argument, wherever it stands, including a call that a macro returns. `prn`
written alone as a value, as in `(for-each (iter items) prn)`, is the
one-value function `print-form`, and reports nothing.

## Erroneous example

```knave
(defn main () (let (score 42) (prn)))
```

## Fixes

Print the value you meant:

```knave
(defn main ()
  (let (score 42) (prn score)))
```

Or call `println` with no argument to print an empty line:

```knave
(defn main ()
  (let (score 42) (println)))
```
