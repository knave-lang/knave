The qualified name of a variant that carries a payload, such as `shape/circle`
or `option/some`, written alone where a value goes, as a `let` value or as an
argument to a function such as `map`, reports this error. A variant without a
payload, such as `shape/point`, is a value by itself.

The prelude's bare names `some` and `ok` are values, so `(map (iter numbers)
some)` is no error. The short name of a program's variant, such as `circle`,
reports `L0201` in value position.

## Erroneous example

```lisp
(defenum shape (circle f64) point)

(defn main ()
  (let (shapes (collect (map (iter (vec 1.0 2.0)) shape/circle)))
    (println (len shapes))))
```

## Fixes

Wrap the constructor in a function that calls it:

```lisp
(defenum shape (circle f64) point)

(defn main ()
  (let (shapes (collect (map (iter (vec 1.0 2.0))
                             (fn (radius) (shape/circle (deref radius))))))
    (println (len shapes))))
```

Call the constructor where the value is needed:

```lisp
(defenum shape (circle f64) point)

(defn main ()
  (let (unit-circle (shape/circle 1.0)
        nothing shape/point)
    (match unit-circle
      ((circle radius) (println radius))
      (point (println "point")))
    (match nothing
      (point (println "point"))
      (_ (println "circle")))))
```
