`derive` writes trait implementations for a struct or an enum that the same file
defines. Here its first argument resolves to something else: a built-in type
such as `string`, a trait, or a struct or enum from another module, such as the
prelude's `option`.

A name that resolves to nothing reports `L0201` instead.

## Erroneous example

```knave
(derive string clone)

(defn main () (println "derived"))
```

## Fixes

Define a struct that holds the value, and derive the trait for it:

```knave
(defstruct label
  :id i64)

(derive label clone)

(defn main ()
  (let (first (->label :id 1)
        second (clone first))
    (println (:id second))))
```
