A `type` signature, a struct field and a variant's payload each take a type.
Here one of them holds a number, a string, an empty list `()`, or a list whose
head is not a symbol, such as `(5 i64)`.

A list whose head is a symbol that builds no type, such as `(i64)`, reports
`L0212` instead, and a symbol that names no type, such as `println`, reports
`L0201`.

## Erroneous example

```lisp
(defstruct point :x "i64" :y i64)

(defn main ()
  (println (:x (->point :x 1 :y 2))))
```

## Fixes

Write the type's name without quotes:

```lisp
(defstruct point :x i64 :y i64)

(defn main ()
  (println (:x (->point :x 1 :y 2))))
```
