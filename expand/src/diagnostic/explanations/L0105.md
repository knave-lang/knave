An atom that starts with a digit, or with `+` or `-` followed by a digit, is a
number, so it must read as one. An integer is digits, and may hold `_` after
its first digit, as in `1_000`. A float is digits, a `.` and more digits, or
either of those followed by an exponent such as `e9` or `e-3`. This atom starts
like a number but is neither, as `3x`, `1.2.3`, `1.` and `0xff` are. knave has
no hexadecimal or binary literals, and a name cannot start with a digit.

## Erroneous example

```knave
(defn main ()
  (println (+ 0xff 1)))
```

## Fixes

Write the number in decimal:

```knave
(defn main ()
  (println (+ 255 1)))
```

Or, when the atom is a name, start it with a letter:

```knave
(defn main ()
  (local x3 3)
  (println x3))
```
