This error reports a library entry under `libraries` whose name holds a
character other than a lowercase ASCII letter, a digit or a dash, starts with
something other than a lowercase ASCII letter, or has a dash at its end or two
in a row, such as `Hints` or `my_hints`.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```lisp
;; project.knv
(defproject greeter
  (libraries (Hints :path "hints")))
;; src/main.knv
(defn main ()
  (println "hello"))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```

## Fixes

Write the name in lowercase:

```lisp
;; project.knv
(defproject greeter
  (libraries (hints :path "hints")))
;; src/main.knv
(use hints hint)

(defn main ()
  (println (hint)))
;; hints/project.knv
(defproject hints)
;; hints/src/lib.knv
(export hint)

(defn hint () "hello")
```
