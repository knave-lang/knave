Macro code runs while the compiler expands the program. Whatever its step limit,
the size of each value that a built-in builds for it is bounded too. Text that a
built-in builds, such as the result of `string`, `symbol` or `string-lowercase`,
holds at most 16,777,216 bytes. A list that a built-in builds, such as the
result of `list`, `prepend`, `concat`, `string-lines` or `read-form`, holds at
most 4,194,304 values, counting each value inside it and counting a list again
each time it appears, so `(list x x)` grows as fast as a copy. Every note that
`add-module-note` adds counts toward 268,435,456 bytes for the whole program, at
64 bytes for each form of the note plus the bytes of its text.

This error reports the built-in call that passes one of these limits, such as
the call in a macro loop that doubles a text or a list on each step, with the
macro call that ran it.

## Erroneous example

```knave
(use code string)

(def grow
  (fn (text) (recur (string text text))))

(defmacro banner () (grow "="))

(defn main () (println (banner)))
```

## Fixes

Double the text a fixed number of times:

```knave
(use code number-sub string value-eq)

(def grow
  (fn (text count)
    (if (value-eq count 0)
      text
      (recur (string text text) (number-sub count 1)))))

(defmacro banner () (grow "=" 4))

(defn main () (println (banner)))
```
