A `defenum` variant whose first item after the name is a keyword holds
`:field type` pairs, such as `(labeled :text string :size f64)`. This error
reports a field keyword in such a variant that is followed by another keyword,
as in `(labeled :text :size f64)`, by a `(defaults ...)` list, or by nothing,
as in `(labeled :size f64 :text)`.

## Erroneous example

```knave
(defenum shape
  (labeled :text :size f64)
  dot)

(defn main ()
  (match (shape/labeled (str "note") 2.0)
    ((labeled text _) (println text))
    (dot (println "dot"))))
```

## Fixes

Add `string` between `:text` and `:size`:

```knave
(defenum shape
  (labeled :text string :size f64)
  dot)

(defn main ()
  (match (shape/labeled (str "note") 2.0)
    ((labeled text _) (println text))
    (dot (println "dot"))))
```
