Naming a local binding `_` says that the code ignores its value. A read of `_`
reports this error wherever a local binding named `_` is in scope, such as a
parameter of a `fn` or `defn`, or a binding of `let` or `loop`, even inside a
`match` arm whose own pattern is `_`.

A `_` pattern in a `match` arm binds nothing at all, so reading `_` where no
local binding of `_` is in scope reports `L0201` instead.

## Erroneous example

```knave
(defn pick-second (_ right) _)

(defn main ()
  (println (pick-second 1 2)))
```

## Fixes

Return the parameter that the body means:

```knave
(defn pick-second (_ right) right)

(defn main ()
  (println (pick-second 1 2)))
```

When the body needs the first argument, bind it as `left`:

```knave
(defn pick-first (left _) left)

(defn main ()
  (println (pick-first 1 2)))
```
