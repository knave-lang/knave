A keyword that declares a name, such as a field of a `defstruct`, a field of a
`defenum` variant or a parameter of a `defn` whose parameters are keywords,
starts with one `:` and the rest is the name. This error reports such a
keyword with `:` at its end, such as `:email:` or `:email::`, or one made only
of `:` characters, such as `::`.

A lone `:` reports `L0301`. A keyword that reads a field, such as `:x:` in
`(:x: p)`, declares nothing, so it does not report this error.

## Erroneous example

```knave
(defstruct user :name str :email: str)

(defn main ()
  (println (:email (->user :name "ana" :email "ana@example.org"))))
```

## Fixes

Write the keyword with one `:`, at its start:

```knave
(defstruct user :name str :email str)

(defn main ()
  (println (:email (->user :name "ana" :email "ana@example.org"))))
```
