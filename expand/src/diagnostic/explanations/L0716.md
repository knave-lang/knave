A crate entry under `dependencies` or `dev-dependencies` names a crate of Rust's
crate registry by its version, such as `(rand "0.8")`, or a crate on disk by
`:path`. This error reports a crate entry with neither, such as `(rand)` or
`(rand :features ("std"))`.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter (dependencies (rand)))
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

With `"0.8"` in the entry, `knave check` reads the project, and `knave build`
fetches the crate from the registry when it builds the program:

```knave
;; knave check
;; project.knv
(defproject greeter (dependencies (rand "0.8")))
;; src/main.knv
(defn main () (println "hello"))
```
