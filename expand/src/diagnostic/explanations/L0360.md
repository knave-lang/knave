This error reports a flag of a `deftask` whose keyword is `:help`, wherever the
parameter list reaches it, with or without a type or a default. The compiler
tests each keyword before the items after it, so `(:help false who)` reports
this error too. A positional item after an earlier flag, as in `(:loud false who
:help)`, reports `L0358` first. `knave task <name> --help` shows the task's
usage line and docstring and exits 0 without running the body. The test is
exact, so a positional parameter named `help` and a flag such as `:Help` or `:h`
pass.

## Erroneous example

```lisp
;; knave task greet Ada
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/greet.knv
(deftask greet (who :help false)
  (if help
    (println "greet <who> prints a greeting")
    (println (str "hello, " who))))
```

## Fixes

Write the text in the task's docstring, which `--help` prints:

```lisp
;; knave task greet --help
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/greet.knv
(deftask greet (who)
  "Prints a greeting to `who`."
  (println (str "hello, " who)))
```

Or give the flag a name that the runner leaves to the task:

```lisp
;; knave task greet Ada --usage
;; project.knv
(defproject chores)
;; src/main.knv
(defn main () (println "run a task with knave task"))
;; tasks/greet.knv
(deftask greet (who :usage false)
  (if usage
    (println "greet <who> prints a greeting")
    (println (str "hello, " who))))
```
