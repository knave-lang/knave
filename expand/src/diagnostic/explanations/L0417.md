The head of a `defstruct`, `defenum`, `struct`, `enum` or `rust-type` lists its
type parameters as bare names. This error reports a parameter there written as
a list of the name followed by traits, such as `(a display)`, because Rust
would then demand those traits at every use of the type. A list that holds only
the name is accepted. A function's `where` is the place where a type parameter
requires traits.

This error also reports a lifetime followed by traits, such as `('a clone)`,
in a type head or in any `where`.

## Erroneous example

```knave
(defstruct (labeled (a display)) :value a)

(defn main () (println (:value (->labeled 1))))
```

## Fixes

Declare `labeled` with a bare `a`, and write `(a display)` in the signature of
the function that prints the value:

```knave
(defstruct (labeled a) :value a)

(type show (where ((a display)) (fn ((ref (labeled a))) unit)))

(defn show (item) (println (:value item)))

(defn main () (show (ref (->labeled 1))))
```
