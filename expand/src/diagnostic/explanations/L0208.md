A definer such as `defn`, `def`, `defstruct` or `defenum` names something that
the whole module sees, so it stands at the top level of a file. This definer
is inside a body, such as a function's body or a `let`. A body binds its own
names with `local` and `let`, and those names last only until the body ends.

## Erroneous example

```lisp
(defn main ()
  (defn helper (n) (* n 2))
  (println (helper 2)))
```

## Fixes

Move the definition to the top level of the module:

```lisp
(defn helper (n) (* n 2))

(defn main ()
  (println (helper 2)))
```

Or bind a function to a local name inside the body:

```lisp
(defn main ()
  (local helper (fn (n) (* n 2)))
  (println (helper 2)))
```
