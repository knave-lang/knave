This error reports a module of a library fetched from git, or of a library that
such a library lists, whose file is a symbolic link to a file outside the
library's checkout. A checkout holds one commit of the repository, and a file
outside it is not part of that commit. The error is labeled on the module's
path in the `use` that loads it. A link whose target does not exist reports
`L0204` instead.

`knave check`, `types`, `lint`, `expand`, `emit`, `build`, `run`, `test`,
`task`, `eval`, `repl` and `doc --write` report it when they load the module.
`knave fmt` loads no module, so it does not report it.

## Described example

The explanation tests cannot make a git repository, so they run no example
here. A library `keys`, fetched with `:git` and `:rev`, holds `src/lib.knv`,
which reads `(use table key)`, and `src/table.knv` is a symbolic link to a file
in another folder of the machine. A project that lists `keys` and uses it
reports this error at that `use`.

## Fixes

The checkout must hold the module's file itself, not a link to it. Once the
library's authors have committed the file, a new `:rev` names that commit.
