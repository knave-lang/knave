`(docstring term)` returns the docstring of `term` as a string. This error
reports a term that has none: a name without one, such as a name that a
`defn` or a `defstruct` with no docstring defines, or a name that `let` binds;
a module looked up as `(module path)` whose docstring is missing or blank; or
a listing such as `(dir)`, `(dir module)`, `(apropos text)` or
`(find-doc text)`, which never has one.

A `defn` whose body holds only a string lacks a docstring: the string is the
value the function returns. `doc-page` and `doc-body` take the same terms and
give a page for each of them, and a name that refers to nothing reports
`L0201`.

## Erroneous example

```knave
(defn twice (x) (* 2 x))

(defn main ()
  (println (docstring twice)))
```

## Fixes

Document the function:

```knave
(defn twice (x)
  "Doubles a number."
  (* 2 x))

(defn main ()
  (println (docstring twice)))
```

Or print the page of the term with `doc-page`, which shows its header when it
lacks a docstring:

```knave
(defn twice (x) (* 2 x))

(defn main ()
  (println (doc-page twice)))
```
