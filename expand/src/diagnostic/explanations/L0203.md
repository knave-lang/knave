A name can be bound only once in the same place. A module that defines a name
twice, or defines a name that a `use` already imports, or imports one name from
two modules, binds it twice. The same holds for a name given twice in one
parameter list, in one `loop` binding list, or as two fields of one struct.

A module's own definition may share a name with the prelude: it replaces the
prelude's name in that module. A `local` may also reuse the name of an earlier
`local` in the same body, and the later binding hides the earlier one.

## Erroneous example

```lisp
(defn area (width height) (* width height))

(defn area (side) (* side side))

(defn main ()
  (println (area 3)))
```

## Fixes

Give each definition its own name:

```lisp
(defn area (width height) (* width height))

(defn square-area (side) (* side side))

(defn main ()
  (println (area 2 5))
  (println (square-area 3)))
```

When the second binding comes from a `use`, leave that name out of the `use`
and keep the module's own definition.
