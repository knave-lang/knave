In a project file, a key such as `:entry` or `:path` takes the form right after
it as its value. This error reports a key that the form reads, with nothing
after it, or with another key right after it, such as `:entry :version "1.0.0"`.
In a library entry, a `:path` or `:git` without a value counts as absent, so an
entry with no other `:path` or `:git` also reports `L0712`.

The compiler reports each such mistake in the file, not only the first. Every
command that reads the project reports it, run in the project's folder or below
it, or given a file there: `knave check`, `types`, `lint`, `expand`, `emit`,
`build`, `run`, `test`, `task`, `eval`, `repl`, `doc --write`, `add` and
`remove`. `knave fmt` reports it as a warning and formats the files all the
same.

The project file of a library that the project lists reports it the same way, at
that file.

## Erroneous example

```knave
;; project.knv
(defproject greeter :entry)
;; src/main.knv
(defn main () (println "hello"))
```

## Fixes

Give the key its value:

```knave
;; project.knv
(defproject greeter :entry "src/main.knv")
;; src/main.knv
(defn main () (println "hello"))
```

Or remove the key, and the setting takes its default, here `src/main.knv`:

```knave
;; project.knv
(defproject greeter)
;; src/main.knv
(defn main () (println "hello"))
```
