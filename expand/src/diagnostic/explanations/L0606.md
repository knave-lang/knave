When a body changes a parameter that has no written type, such as with `set!` of
the parameter or of a field, with `push!`, or by passing it to a `mut`
parameter, and does not move it, the function borrows the caller's value
mutably, so the change reaches the caller. A result that is a closure, or an
iterator when the parameter is Copy, names in `use<...>` only the lifetimes that
it keeps, so the caller may read the changed value while the result lives.
Rust's `use<...>` cannot name a parameter that takes a function or an iterator,
so this error reports a top-level function that does all three: changes such a
parameter, takes a function or an iterator, and returns a closure or an
iterator. A parameter of a Copy type, such as `i64`, reports it with either
result. A parameter of another type, such as `string`, a vector or a struct,
reports it only when the function returns a closure.

A parameter whose binder writes its type never reports this error: one written
as `(count (mut i64))` keeps its borrow in the result, so the caller cannot read
the value while the result lives. A type written in a `type` signature, such as
`i64`, makes the parameter a value of the function's own, so the change does not
reach the caller. A result that holds the parameter's borrow anyway, such as a
closure that reads a `match` binder of the parameter, reports nothing. A
returned closure that uses the changed parameter itself reports `L0517` instead.

## Erroneous example

```lisp
(defn tally! (calls announce)
  (set! calls (+ calls 1))
  (announce)
  (fn (value) (* value 2)))

(defn main ()
  (let (calls 0
        double (tally! calls (fn () (println "ready"))))
    (println (double 21))
    (println calls)))
```

## Fixes

Call the function argument in the caller, so the function that changes the
value takes no function, and the caller reads the changed value:

```lisp
(defn tally! (calls)
  (set! calls (+ calls 1))
  (fn (value) (* value 2)))

(defn main ()
  (let (calls 0)
    (println "ready")
    (let (double (tally! calls))
      (println (double 21))
      (println calls))))
```

Or declare the function with a `type` signature, whose written `i64` passes
the value itself, so the caller prints 0:

```lisp
(type tally! (fn (i64 (fn () unit)) (fn (i64) i64)))

(defn tally! (calls announce)
  (set! calls (+ calls 1))
  (announce)
  (fn (value) (* value 2)))

(defn main ()
  (let (calls 0
        double (tally! calls (fn () (println "ready"))))
    (println (double 21))
    (println calls)))
```
