A struct value holds one value for each field. This error reports a field label
that a construction of a struct or of an enum variant with named fields, or an
update of a struct, writes a second time, such as in a `->point` call or an enum
variant call with `:field value` pairs, a `new` form or an `assoc`. The compiler
reads the labels in written order and reports the second one, before it looks
for a field that the call leaves out. An earlier label that names no field
reports `L0408` first, even when that label is the one repeated, and an earlier
value of the wrong type reports its mismatch first.

A struct definition that declares a field twice reports `L0203` instead, a
pattern that names a field twice reports `L0461`, and a call by name of a
function that passes a parameter twice reports `L0320`.

## Erroneous example

```knave
(defstruct point
  :x i64
  :y i64)

(defn main ()
  (println (:y (->point :x 1 :x 2))))
```

## Fixes

Label the second value with the field it was meant for:

```knave
(defstruct point
  :x i64
  :y i64)

(defn main ()
  (println (:y (->point :x 1 :y 2))))
```
