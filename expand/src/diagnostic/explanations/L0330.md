In a `defrule` template, a part followed by `...` is filled once for each
match of the pattern variables it uses that the pattern repeats. This error
reports a call where two such variables of one repeated part matched a
different number of forms. The check runs at each call of the rule, at any
depth of nested `...`, and in `defrule-with-value` too, so a call whose
lengths agree reports nothing.

A repeated variable used in the template without `...` after it reports
`L0301`.

## Erroneous example

```lisp
(defrule zip (((a ...) (b ...)) (vec (pair a b) ...)))

(defn main () (println (len (zip (1 2) (4 5 6)))))
```

## Fixes

Pass three forms in the first list as well:

```lisp
(defrule zip (((a ...) (b ...)) (vec (pair a b) ...)))

(defn main () (println (len (zip (1 2 3) (4 5 6)))))
```
