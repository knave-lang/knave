When a `match` arm follows arms that already match every value it matches,
this warning reports that arm, because the value never reaches it. The earlier
arms may cover it alone, as `_` or a bare name does, or together, as one arm per
variant of an enum does before a last `_`.

Every command that checks the program prints the warning: `knave check`,
`knave build`, `knave run`, `knave emit`, `knave types`, `knave test`,
`knave repl`, `knave lint` and `knave doc --types`. `knave doc --write` checks
each module's types too, but prints no warning of that check. The program
still builds and runs, and only `knave lint` exits with status 1 because of
it.

## Erroneous example

```knave
(enum side left right)

(defn label (s)
  (match s (_ "any side") (side/left "left")))

(defn main ()
  (println (label side/left)))
```

## Fixes

Put the narrower arm before the arm that covers it:

```knave
(enum side left right)

(defn label (s)
  (match s (side/left "left") (_ "any side")))

(defn main ()
  (println (label side/left)))
```

Or remove the arm, if the earlier arm gives the value you want:

```knave
(enum side left right)

(defn label (s)
  (match s (_ "any side")))

(defn main ()
  (println (label side/left)))
```
