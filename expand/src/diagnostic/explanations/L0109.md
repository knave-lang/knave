`knave fmt` lays out the code in docstrings: an example paragraph, which holds a
line that starts with `=> `, and a fence whose info string is empty or `knave`.
This warning reports such code that the reader cannot turn into forms: an
unclosed list, code of another language in an untagged fence, or code nested
past the reader's limit of 1,024 lists. A result over several lines is refused
too when one of its later lines starts no further right than its code, because
that line would start new code.

Only `knave fmt` reports it, with or without `--check`, in every docstring:
those of definitions, `document` and `module`. The formatter changes nothing in
that code and lays out the rest of the file. The warning does not change the
exit status.

## Erroneous example

```knave
;; knave fmt
;; project.knv
(defproject pairs)
;; src/main.knv
(defn pairs (x)
  "Pairs a number.

  (pairs 1)
  => (vec 1
  1)"
  (vec x x))
```

## Fixes

Line up each later line of the result with the value it continues:

```knave
;; knave fmt
;; project.knv
(defproject pairs)
;; src/main.knv
(defn pairs (x)
  "Pairs a number.

  (pairs 1)
  => (vec 1
       1)"
  (vec x x))
```
