A call passes one argument for each positional parameter of the function it
calls, in order. This call passes a different number. A positional parameter has
no default value, so every positional parameter needs its argument.

## Erroneous example

```lisp
(defn area (width height) (* width height))

(defn main ()
  (println (area 2)))
```

## Fixes

Pass every argument:

```lisp
(defn area (width height) (* width height))

(defn main ()
  (println (area 2 3)))
```

Or define a function that takes only the arguments you have:

```lisp
(defn square-area (side) (* side side))

(defn main ()
  (println (square-area 2)))
```
