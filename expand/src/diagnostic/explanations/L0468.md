A `mismatch-help` states the help for one pair of types, an expected type and a
found type, so a program holds at most one row for each pair. This error
reports each row after the first for the same pair, whatever either row says.
The prelude's rows count: the prelude already states the help where an `int`
is expected and a `usize` is found, so a program's own row for that pair
reports this error.

## Erroneous example

```knave
(mismatch-help u8 int "narrow it with `(convert {value})`")

(mismatch-help u8 int "pass a `u8` instead of {value}")

(defn main ()
  (println 1))
```

## Fixes

Keep one row for the pair:

```knave
(mismatch-help u8 int "narrow it with `(convert {value})`")

(defn main ()
  (println 1))
```
