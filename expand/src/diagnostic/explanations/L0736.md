A project's `:knave` names the Knave version that the project uses, and this
error reports a `knave` older than that version. An older compiler can lack a
form or a rule that the project relies on, and its results would differ from
those of the Knave that CI installs from the same key. `knave upgrade` refuses
to lower the key for the same reason.

Every command that finds the project reports it. A library's `:knave` is never
checked. A project without `:knave` is never checked either.

## Described example

A project that records Knave 99.0.0, checked by any earlier `knave`, reports it:

```text
(defproject greeter :knave "99.0.0")
```

## Fixes

Install the version the project uses, with
`cargo install knave --version 99.0.0 --locked`.
