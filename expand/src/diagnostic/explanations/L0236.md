`(type name type)` writes the type of a `def` or a `defn` that the same file
defines. This code reports a `name` that resolves to anything else, such as a
definition from another module, as the prelude's `println` or `none`, a variant
constructor such as `shape/circle`, `true` or `false`, a kernel form such as
`if`, or a macro. A macro of this module passes only when its name, used as a
value, expands to a function that the macro defined in this module.

A name that resolves to nothing reports `L0201` instead.

## Erroneous example

```lisp
(type println (fn (i64) unit))

(defn main ()
  (println 1))
```

## Fixes

Define a function of your own and give the signature its name:

```lisp
(type show-count (fn (i64) unit))
(defn show-count (n) (println n))

(defn main ()
  (show-count 1))
```
