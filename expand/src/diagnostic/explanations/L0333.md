Each `deftest` adds a test to its module under the name written after
`deftest`. This error reports a `deftest` whose name is already the name of an
earlier test in the same module, whatever the bodies and docstrings of the two
tests hold. The compiler matches test names within one module, so a test in
another module may take the same name.

Every command expands every test, so `knave check` and `knave run` report this
error as `knave test` does.

A test name that is not a symbol, such as `:pads`, reports `L0301` instead.

## Erroneous example

```knave
(defn pad (text) (str " " text))

(deftest pads
  (assert (= (pad "a") " a")))

(deftest pads (assert (= (pad "") " ")))

(defn main () (println (pad "x")))
```

## Fixes

Call the second test `pads-empty`:

```knave
(defn pad (text) (str " " text))

(deftest pads
  (assert (= (pad "a") " a")))

(deftest pads-empty
  (assert (= (pad "") " ")))

(defn main () (println (pad "x")))
```

Or check both cases in one test:

```knave
(defn pad (text) (str " " text))

(deftest pads
  (assert (= (pad "a") " a"))
  (assert (= (pad "") " ")))

(defn main () (println (pad "x")))
```
