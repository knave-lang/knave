The file `project.knv` at a project's root describes the project, its name,
entry and libraries, so the module path `project` stays free of code. A `use`
of the bare path `project` reports this error in any file, whether or not a
project exists. So does a `use` of a library named `project`: the project file
accepts that name, but no program can import the library. A longer path that
starts with `project/`, such as `project/settings`, is an ordinary module path.

## Erroneous example

```lisp
(use project greeting)

(defn main ()
  (println greeting))
```

## Fixes

Keep the definition in a module of another name, or in the file that uses it:

```lisp
(def greeting "hi")

(defn main ()
  (println greeting))
```
