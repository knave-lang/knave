Macro code runs in the compiler's interpreter. It can run the kernel forms,
the `code` module, and functions that use only those. This error reports
macro code that reaches a `rust` form through a name: a definition whose
value is a `rust` form, such as `(def seven (rust "7" i64))`, or a macro whose
expansion there is a `rust` form, such as `+`, `*`, `str` and `println`. Macro
code covers a macro's body and every function that it calls, prelude functions
such as `sum` included. The compiler checks it where the macro is defined, so
a macro that nothing calls, or a branch that never runs, reports this error
too.

A `rust` form written in macro code itself reports `L0319` instead.

## Erroneous example

```knave
(use code len)

(defmacro count-plus-one (forms ...)
  (+ (len forms) 1))

(defn main ()
  (println (count-plus-one a b c)))
```

## Fixes

Add the numbers while the macro runs, with `number-add`:

```knave
(use code len number-add)

(defmacro count-plus-one (forms ...)
  (number-add (len forms) 1))

(defn main ()
  (println (count-plus-one a b c)))
```

Or leave the addition to the program:

```knave
(use code len)

(defmacro count-plus-one (forms ...)
  (template (+ (unquote (len forms)) 1)))

(defn main ()
  (println (count-plus-one a b c)))
```
