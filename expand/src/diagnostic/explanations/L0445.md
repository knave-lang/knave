A trait that `rust-trait` binds, or that `deftrait` binds with a `rust`
clause, such as `display` or `eq`, is defined in Rust outside the program.
This error reports an `impl` of such a trait whose implementor is not a type
declared as a struct or an enum, such as a primitive like `i64`, an applied
type like `(vec i64)`, or a type that `deftype` names. The `display` macro
writes an `impl`, so it reports this error too.

A trait that the program defines with `deftrait` and no `rust` clause takes
these implementors, so its `impl` for `i64` or `(vec a)` is fine.

## Erroneous example

```knave
(display (vec i64) (numbers) "numbers")

(defn main () (println (vec 1 2)))
```

## Fixes

Wrap the vector in a struct, and write the `display` for the struct:

```knave
(defstruct scores :values (vec i64))

(display scores (s) "scores")

(defn main () (println (->scores :values (vec 1 2))))
```

Or print the vector's printed form with `prn`:

```knave
(defn main () (prn (vec 1 2)))
```
