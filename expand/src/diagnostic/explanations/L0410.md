A field read, such as `(:x value)` or `(field value x)`, and a struct update,
such as `assoc` with a keyword key, work on a struct. This error reports one
whose value has a known type that is not a struct, such as a number, a string,
a `bool`, a vector or an enum, even an enum whose variants have named fields. A
read looks through borrows, so `(:x p)` works when `p` is a `(ref point)`.

An update moves the other fields of its base into the new struct, so it reports
this error when its base is a borrow of a struct, such as a parameter of type
`(ref point)` or an element that `at` reads.

When the value's type is still unknown, as for an integer literal that nothing
has fixed, a read reports `L0407` instead, or `L0401` when exactly one struct
declares the field.

## Erroneous example

```knave
(defstruct point
  :x i64
  :y i64)

(defn main ()
  (let (points (vec (->point 1 2) (->point 3 4)))
    (println (:x points))))
```

## Fixes

Read the field of one element:

```knave
(defstruct point
  :x i64
  :y i64)

(defn main ()
  (let (points (vec (->point 1 2) (->point 3 4)))
    (println (:x (at points 0)))))
```

Or read the field of each element:

```knave
(defstruct point
  :x i64
  :y i64)

(defn main ()
  (let (points (vec (->point 1 2) (->point 3 4)))
    (println (sum (map (iter points) :x)))))
```
