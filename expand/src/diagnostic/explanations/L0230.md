In the kernel `enum` form, a case written as `(labeled (struct ...))` takes
named fields from its `struct` body, and that body must stand alone after the
case's name. A case that puts a `struct` body beside a type, or beside a
second `struct` body, is this error. `defenum` writes a case's fields flat,
as in `(labeled :text string :size float)`, and reports its own errors for a
case that mixes the two, so this error comes from `enum` written directly.

## Erroneous example

```knave
(enum shape
  (circle float)
  (labeled (struct (text string)) float))

(defn main ()
  (let (tag (shape/labeled (str "box") 2.0))
    (match tag
      ((shape/labeled text size) (println text " " size))
      ((shape/circle radius) (println radius)))))
```

## Fixes

Move every field into the `struct` body:

```knave
(enum shape
  (circle float)
  (labeled (struct (text string) (size float))))

(defn main ()
  (let (tag (shape/labeled (str "box") 2.0))
    (match tag
      ((shape/labeled text size) (println text " " size))
      ((shape/circle radius) (println radius)))))
```

Or write every part as a type:

```knave
(enum shape (circle float) (labeled string float))

(defn main ()
  (let (tag (shape/labeled (str "box") 2.0))
    (match tag
      ((shape/labeled text size) (println text " " size))
      ((shape/circle radius) (println radius)))))
```
