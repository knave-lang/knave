A project's `libraries` give each library a name, and a `use` in the program
whose path starts with that name, such as `hints` or `hints/extra`, loads from
the library. This warning reports such a `use` when the program also has a
module file or a folder of that name at its source root, such as `hints.knv` or
`hints/`, which no `use` of that path can then reach. A `use` in a test file or
a task file reports it for such a file or folder in the source root too, and for
one in `tests/` or `tasks/` when a command runs a single test or task file. A
command that reads a whole folder of test or task files, or `knave doc --write`,
which reads the source root, reports a file there whose module path starts with
the library's name, such as `tests/hints.knv` or `src/hints.knv`, as the error
`L0258` instead. `knave check` and `knave lint` given a task file do both: they
report this warning at the file's `use` and `L0258` at the file under `tasks/`.
Each name reports it once, for the first match the compiler finds: a file before
a folder of that name, and one in `tests/` or `tasks/` before one in the source
root.

Only a `use` in the program reports it: a `use` in a library's module that names
a library it lists reports nothing, even beside a file of that name. When the
project does not list the library itself, because only another library lists it,
the same `use` reports the error `L0253` instead.

## Erroneous example

```knave
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout)
(use tips tip)

(defn main () (println (shout tip)))
;; src/hints.knv
(export tip)

(def tip "rest")
;; src/tips.knv
(export tip)

(def tip "drink water")
;; libs/hints/project.knv
(defproject hints)
;; libs/hints/src/lib.knv
(export shout)

(defn shout (text) (str text "!"))
```

## Fixes

Move the local module into a folder, and use it by its longer path:

```knave
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout)
(use local/hints tip)

(defn main () (println (shout tip)))
;; src/local/hints.knv
(export tip)

(def tip "rest")
;; libs/hints/project.knv
(defproject hints)
;; libs/hints/src/lib.knv
(export shout)

(defn shout (text) (str text "!"))
```

Or delete `src/hints.knv`, when no `use` needs it:

```knave
;; project.knv
(defproject app (libraries (hints :path "libs/hints")))
;; src/main.knv
(use hints shout)
(use tips tip)

(defn main () (println (shout tip)))
;; src/tips.knv
(export tip)

(def tip "drink water")
;; libs/hints/project.knv
(defproject hints)
;; libs/hints/src/lib.knv
(export shout)

(defn shout (text) (str text "!"))
```
