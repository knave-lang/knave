A module path names a file from the root directory, one name per directory, so
each file has one module path. A `use` whose path holds a `.` or `..` part, such
as `./shapes` or `geometry/../shapes`, reports this error, because the same file
would load a second time as a different module. The help writes the path from
the root directory, unless the path leaves it.

## Erroneous example

```knave
(use ./shapes area)

(defn main () (prn (area 2)))
```

## Fixes

Write the path from the root directory:

```knave
(use shapes area)

(defn main () (prn (area 2)))
```
