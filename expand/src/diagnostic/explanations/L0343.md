A `deftrait` with a `(rust "Path")` clause names a Rust trait, and the forms
after the clause are the types that implement it, with entries such as
`(method name type)`, `help` and `where`. This error reports a form after the
clause that is a list of two items whose second item is a `fn` or `where`
type, such as `(area (fn ((ref self)) f64))`, which is the shape of a method
in a trait of the program. A type of that shape, such as
`(box (fn (i64) i64))`, reports this error too.

`deftrait` checks these forms before the clause itself, so a clause with a
second string still reports this error first.

## Erroneous example

```knave
(deftrait hex-number
  (rust "std::fmt::LowerHex")
  (digits (fn ((ref self)) string)))

(defn main () (println "hex"))
```

## Fixes

Keep the clause, and follow it with `i8` and `i16`:

```knave
(deftrait hex-number (rust "std::fmt::LowerHex") i8 i16)

(defn main () (println "hex"))
```

Or drop the clause to define a trait of the program:

```knave
(deftrait hex-number (digits (fn ((ref self)) string)))

(impl hex-number i64
  (digits (self) (str self)))

(defn main () (println (digits 255)))
```
